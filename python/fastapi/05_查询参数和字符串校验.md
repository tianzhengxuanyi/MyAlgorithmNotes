## 一、章节笔记

### 1. 为什么需要 `Query`

上一章只能声明参数类型与默认值。本章要为参数添加**额外校验和元数据**（长度、正则、别名、文档说明等），需使用 `fastapi.Query`，并配合 `typing.Annotated`。

基础例子：`q` 是可选字符串，但只要提供就"最长 50 字符"：

```python
from typing import Annotated
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/items/")
async def read_items(q: Annotated[str | None, Query(max_length=50)] = None):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results
```

> FastAPI **0.95.0** 起支持并推荐 `Annotated`；低于此版本会报错，建议至少升级到 0.95.1。

### 2. `Annotated` 写法 vs 旧的默认值写法

同一约束有两种写法，**推荐 `Annotated`**：

```python
# 推荐：Annotated
q: Annotated[str | None, Query(max_length=50)] = None

# 旧式（0.95.0 之前）：把 Query 当默认值
q: str | None = Query(default=None, max_length=50)
```

| 对比点 | Annotated（推荐） | 旧式默认值 |
|---|---|---|
| 默认值位置 | 函数参数真正的 `= None` | `Query(default=None)` 内 |
| 直接调用函数 | 按 Python 直觉工作，编辑器/运行时能检查必填参数 | 忘了传参会得到 `QueryInfo` 对象而非预期值，且无报错 |
| 与其他工具配合 | 同一函数可用于 Typer 等 | 不便复用 |
| 默认值冲突 | 不允许 `Query(default=...)` 与函数默认值同时写 | 只能写在 `Query` 内 |

❌ 错误示例（默认值不一致，不允许）：

```python
q: Annotated[str, Query(default="rick")] = "morty"   # 到底哪个是默认值？
```

✅ 正确：

```python
q: Annotated[str, Query()] = "rick"        # 推荐
q: str = Query(default="rick")             # 旧代码库可见
```

`Annotated` 的优势核心：**函数默认值就是真正的默认值**，符合 Python 直觉，脱离 FastAPI 直接调用函数也不会出错。

### 3. 字符串专用校验

`Query` 支持多种字符串约束，可组合使用：

```python
from typing import Annotated
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/items/")
async def read_items(
    q: Annotated[
        str | None,
        Query(min_length=3, max_length=50, pattern="^fixedquery$"),
    ] = None,
):
    results = {"items": [{"item_id": "Foo"}, {"item_id": "Bar"}]}
    if q:
        results.update({"q": q})
    return results
```

| 参数 | 含义 |
|---|---|
| `min_length` | 最小长度 |
| `max_length` | 最大长度 |
| `pattern` | 正则表达式，值必须匹配 |

正则 `^fixedquery$` 拆解：`^` 表示以此开头、`fixedquery` 表示精确等于该串、`$` 表示到此结束。正则不是必须掌握的，需要时再用。

添加校验后 FastAPI 会：校验数据、出错时给出清晰错误、并把该参数记录进 OpenAPI（出现在文档 UI）。

### 4. 默认值与必填

- 任何默认值（包括 `None`）都让参数变为**可选**：

```python
q: Annotated[str, Query(min_length=3)] = "fixedquery"
```

- 配合 `Query` 又要**必填**时，不写默认值即可：

```python
q: Annotated[str, Query(min_length=3)]          # 必填
```

- **`str | None` 不会让参数变为可选**：没有默认值时依然必填。且查询参数以字符串传入，没有内置的 `None` 表示——`?q=None`/`?q=null` 传的是字符串 `"None"`/`"null"`，`?q=` 传空串（无法通过 `min_length=3`）。要允许省略并用 `None`，必须写 `= None`（与 JSON 请求体可含显式 `null` 不同）。

### 5. 查询参数列表 / 多值

要接收同一参数多次出现（如 `?q=foo&q=bar`），把类型声明为 `list`：

```python
from typing import Annotated
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/items/")
async def read_items(q: Annotated[list[str] | None, Query()] = None):
    return {"q": q}
```

- 访问 `/items/?q=foo&q=bar` → `{"q": ["foo","bar"]}`。
- **必须显式使用 `Query`**，否则 `list` 类型会被解释为请求体。
- 可设默认列表：`q: Annotated[list[str], Query()] = ["foo","bar"]`。
- 可只用 `list`（不指定元素类型），但此时 FastAPI **不校验列表内容**；`list[int]` 才会校验并记录元素必须是整数。

### 6. 声明更多元数据

元数据写入 OpenAPI，供文档 UI 与外部工具使用（不同工具支持程度不同）：

```python
from typing import Annotated
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/items/")
async def read_items(
    q: Annotated[
        str | None,
        Query(
            title="Query string",
            description="Query string for the items to search in the database that have a good match",
            min_length=3,
        ),
    ] = None,
):
    ...
```

- `title`：参数标题。
- `description`：参数描述。

### 7. 别名、弃用与从文档中排除

| 需求 | 写法 | 说明 |
|---|---|---|
| URL 名不是合法 Python 变量 | `Query(alias="item-query")` | 函数里用 `q`，URL 里查 `item-query` |
| 标记弃用 | `Query(deprecated=True)` | 文档清晰显示为已弃用 |
| 从 OpenAPI 排除 | `Query(include_in_schema=False)` | 参数仍可用，但不出现在文档 |

别名示例：

```python
q: Annotated[str | None, Query(alias="item-query")] = None
```

此时访问 `/items/?item-query=foobaritems`，函数参数 `q` 收到值。

综合示例（多个约束叠加）：

```python
q: Annotated[
    str | None,
    Query(
        alias="item-query",
        title="Query string",
        description="...",
        min_length=3,
        max_length=50,
        pattern="^fixedquery$",
        deprecated=True,
    ),
] = None
```

### 8. 自定义校验（`AfterValidator`）

当内置参数不够用，用 Pydantic 的 `AfterValidator` 在常规校验之后追加自定义规则（Pydantic 2+）：

```python
import random
from typing import Annotated
from fastapi import FastAPI
from pydantic import AfterValidator

app = FastAPI()

data = {
    "isbn-9781529046137": "The Hitchhiker's Guide to the Galaxy",
    "imdb-tt0371724": "The Hitchhiker's Guide to the Galaxy",
    "isbn-9781439512982": "Isaac Asimov: The Complete Stories, Vol. 2",
}

def check_valid_id(id: str):
    if not id.startswith(("isbn-", "imdb-")):
        raise ValueError('Invalid ID format, it must start with "isbn-" or "imdb-"')
    return id

@app.get("/items/")
async def read_items(
    id: Annotated[str | None, AfterValidator(check_valid_id)] = None,
):
    if id:
        item = data.get(id)
    else:
        id, item = random.choice(list(data.items()))
    return {"id": id, "name": item}
```

要点：

- `AfterValidator(check_valid_id)` 放在 `Annotated` 中；校验函数 `raise ValueError` 即触发校验失败。
- `str.startswith()` 可接收元组，检查是否以其中任一前缀开头。
- Pydantic 还有 `BeforeValidator` 等。
- 需要访问数据库/外部 API 的校验应改用**依赖项（Depends）**；自定义校验器只适合"仅检查请求内数据"的场景。

### 9. 校验参数速查

| 类别 | 参数 |
|---|---|
| 通用 | `alias`、`title`、`description`、`deprecated` |
| 字符串 | `min_length`、`max_length`、`pattern` |
| 自定义 | `AfterValidator`（及 `BeforeValidator`） |
| 文档控制 | `include_in_schema=False` |

### 10. 易错点小结

- ✅ 优先用 `Annotated`，不要把 `Query` 当默认值。
- ✅ `Annotated` 中不要再传 `Query(default=...)`，默认值写在函数参数上。
- ✅ `list` 类型作为查询参数必须配 `Query`，否则被当作请求体。
- ✅ `str | None` 不表示"可选"，可选只看有没有默认值；查询串无法表达 `None`。
- ✅ 元数据依赖工具对 OpenAPI 的支持，部分工具可能不展示全部。

## 二、NestJS 对比

| 维度 | FastAPI（Python） | NestJS（TypeScript） |
|---|---|---|
| 额外校验声明 | `Annotated[str, Query(max_length=50, pattern=...)]` | DTO 字段 + `class-validator` 装饰器 `@Length(3,50)` / `@Matches(regex)` |
| 元数据来源 | `Query` 与类型注解内联在一处 | 校验在 DTO 装饰器、swagger 文档在 `@ApiProperty()`，分散在多处 |
| 默认值风格 | `Annotated` 推荐（函数默认值即真默认值） | `@Query()` 取参 + handler 默认值，或 DTO 内字段初始化 |
| 别名（URL 名≠变量名） | `Query(alias="item-query")` | `@Query('item-query') itemQuery: string`（装饰器里指定键名） |
| 弃用标记 | `Query(deprecated=True)`，自动写入 OpenAPI | `@ApiQuery({ deprecated: true })`（需 `@nestjs/swagger`） |
| 从文档排除 | `Query(include_in_schema=False)` | `@ApiExcludeEndpoint()` 排除整个端点；参数级需 `@ApiQuery({ hidden: true })` |
| 列表/多值参数 | `Annotated[list[str], Query()]` 自动收集 `?q=a&q=b` | `@Query('q') q: string[]` + `ValidationPipe` 的 `transform` 配置 |
| 自定义校验器 | `AfterValidator(check_fn)`（Pydantic 2+） | 自定义 `ValidatorConstraint` + `@Validator()` 或自定义 Pipe |
| 错误响应 | Pydantic 统一 `422` + `loc/type/msg` | `ValidationPipe` 抛 `BadRequestException`（400），可自定义 exceptionFactory |

**核心差异一句话**：FastAPI 把校验、元数据、别名、文档表达全部收敛到 `Annotated[..., Query(...)]` 一个声明里，靠 Pydantic 统一执行；NestJS 则分散在 DTO 的 `class-validator` 装饰器、自定义 Pipe 与 `@ApiQuery()` Swagger 装饰器三处，灵活但样板更多。

## 三、针对性练习题

### 题 1（基础）

用 `Annotated` + `Query` 声明一个可选查询参数 `q`，要求提供时长度在 3～50 之间。

<details>
<summary>参考答案</summary>

```python
from typing import Annotated
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/items/")
async def read_items(
    q: Annotated[str | None, Query(min_length=3, max_length=50)] = None,
):
    return {"q": q}
```

`= None` 使其可选；`Query` 内的 `min_length`/`max_length` 仅在提供值时校验。
</details>

### 题 2（理解）

为什么说"`Annotated` 比把 `Query` 当默认值更好"？请从"直接调用函数"和"默认值一致性"两个角度说明。

<details>
<summary>参考答案</summary>

① 直接调用函数：`Annotated` 写法下函数默认值是真正的 `= None`（或其他值），脱离 FastAPI 直接调用时行为符合 Python 直觉，编辑器能检查必填参数、运行时缺参会报错；旧式写法若忘了传参，函数收到的是 `QueryInfo` 对象而非预期值，且编辑器/运行时都不报错，直到函数内部出错才暴露。

② 默认值一致性：`Annotated` 中不能再写 `Query(default="rick")` 同时函数默认值写 `"morty"`（会造成歧义、不允许）；默认值只能写在函数参数上，来源唯一、清晰。
</details>

### 题 3（辨析/代码）

下面写法中，哪个会让 `q` 成为"必填"？为什么？

```python
A: q: Annotated[str | None, Query(min_length=3)]
B: q: Annotated[str | None, Query(min_length=3)] = None
C: q: Annotated[str, Query(min_length=3)] = None
```

<details>
<summary>参考答案</summary>

A 和 C 必填，B 可选。

判断依据是**是否有函数默认值**，而非类型里是否含 `None`：
- A 无默认值 → 必填；`str | None` 只是说值可以是 `None`，但查询串无法表达 `None`，`?q=None` 传的是字符串 `"None"`。
- B 有 `= None` → 可选，省略时 `q` 为 `None`。
- C 有 `= None` → 可选（尽管类型写的是 `str`，但默认值 `None` 仍让它可选；类型注解主要服务编辑器）。

要允许客户端省略并用 `None`，必须像 B 那样写 `= None`。
</details>

### 题 4（进阶 · NestJS 迁移视角）

NestJS 中通过 DTO 校验字符串：

```ts
class SearchDto {
  @IsOptional()
  @Length(3, 50)
  q?: string;
}
```

请写出等价的 FastAPI 声明，并说明 NestJS 的 `@Length(3, 50)`、`@IsOptional()` 分别对应 FastAPI 的什么。

<details>
<summary>参考答案</summary>

```python
from typing import Annotated
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/items/")
async def read_items(
    q: Annotated[str | None, Query(min_length=3, max_length=50)] = None,
):
    return {"q": q}
```

对应关系：
- `@Length(3, 50)` → `Query(min_length=3, max_length=50)`，都由校验库执行长度约束（NestJS 用 `class-validator`，FastAPI 用 Pydantic）。
- `@IsOptional()` → 函数默认值 `= None`；FastAPI 不靠类型里的 `| None` 判断可选。
- NestJS 需 `ValidationPipe` 开启校验，FastAPI 则由类型注解自动触发，无需额外管道。
</details>

### 题 5（思考）

想让查询参数在 URL 中叫 `item-query`（Python 中不是合法变量名），同时在文档中标为弃用、并支持多次出现收集为列表。请写出声明，并说明 `list` 类型为什么必须配 `Query`。

<details>
<summary>参考答案</summary>

```python
from typing import Annotated
from fastapi import FastAPI, Query

app = FastAPI()

@app.get("/items/")
async def read_items(
    q: Annotated[list[str] | None, Query(alias="item-query", deprecated=True)] = None,
):
    return {"q": q}
```

访问 `/items/?item-query=foo&item-query=bar` → `{"q": ["foo","bar"]}`。

`list` 类型必须显式配 `Query`：FastAPI 的参数定位规则中，`list`/Pydantic 模型这类复合类型默认会被解释为**请求体**；用 `Query()` 显式标注后才会作为查询参数从 URL 中收集。另外，若只写 `list` 而不指定元素类型（如 `list[str]`），FastAPI 不会校验列表内容。
</details>
