## 一、章节笔记

### 1. 从返回 `dict` 说起

上一章的依赖返回的是 `dict`：

```python
async def common_parameters(q: str | None = None, skip: int = 0, limit: int = 100):
    return {"q": q, "skip": skip, "limit": limit}
```

路径操作函数参数 `commons` 得到的就是一个 `dict`。编辑器无法为 `dict` 提供很好的支持（如补全），因为它不知道键和值的类型。用**类**作为依赖可以做得更好——注入的是类的实例，带明确的类型信息。

### 2. 什么是「可调用对象」

依赖的关键不是「函数」，而是 **可调用对象（callable）**：任何 Python 能像函数一样用 `()` 调用的对象。

```python
something()
something(some_argument, some_keyword_argument="foo")
```

**类也是可调用对象**——创建实例就是在「调用」类：

```python
class Cat:
    def __init__(self, name: str):
        self.name = name

fluffy = Cat(name="Mr Fluffy")   # 调用 Cat 得到实例
```

FastAPI 检查的是「它是不是可调用对象」以及它定义的参数，然后像处理路径操作函数一样处理这些参数（含子依赖项）。对完全无参数的可调用对象同样适用。

### 3. 把函数依赖改写成类依赖

把 `common_parameters` 函数改成 `CommonQueryParams` 类，`__init__` 的参数与原来完全一致：

```python
from typing import Annotated

from fastapi import Depends, FastAPI

app = FastAPI()

fake_items_db = [{"item_name": "Foo"}, {"item_name": "Bar"}, {"item_name": "Baz"}]

class CommonQueryParams:
    def __init__(self, q: str | None = None, skip: int = 0, limit: int = 100):
        self.q = q
        self.skip = skip
        self.limit = limit

@app.get("/items/")
async def read_items(commons: Annotated[CommonQueryParams, Depends(CommonQueryParams)]):
    response = {}
    if commons.q:
        response.update({"q": commons.q})
    items = fake_items_db[commons.skip : commons.skip + commons.limit]
    response.update({"items": items})
    return response
```

FastAPI 调用 `CommonQueryParams` 类创建实例，把该实例作为参数 `commons` 传给路径操作函数。两种写法下，`q / skip / limit` 都会被转换、校验并记录到 OpenAPI 模式。

### 4. 类型注解 vs `Depends`（关键辨析）

写法中出现了两次 `CommonQueryParams`：

```python
commons: Annotated[CommonQueryParams, Depends(CommonQueryParams)]
```

两者职责不同：

| 位置 | 作用 |
|---|---|
| `Depends(CommonQueryParams)` 中的类 | **真正被 FastAPI 调用的依赖**；FastAPI 从中提取参数并调用 |
| 前面的类型注解 `Annotated[CommonQueryParams, ...]` | 对 FastAPI **无特殊意义**，不参与转换/校验；仅用于编辑器补全、类型检查 |

因此技术上甚至可以写成 `Annotated[Any, Depends(CommonQueryParams)]` 或 `commons = Depends(CommonQueryParams)`，运行照常。但仍**鼓励声明类型**——否则编辑器不知道 `commons` 是什么，无法补全与检查。

### 5. 快捷方式：`Depends()` 省略参数

当依赖明确是一个类、FastAPI 只需调用它创建实例时，可省掉 `Depends` 里的类名：

```python
# 完整写法
commons: Annotated[CommonQueryParams, Depends(CommonQueryParams)]

# 快捷写法
commons: Annotated[CommonQueryParams, Depends()]
```

完整等价示例：

```python
from typing import Annotated

from fastapi import Depends, FastAPI

app = FastAPI()

fake_items_db = [{"item_name": "Foo"}, {"item_name": "Bar"}, {"item_name": "Baz"}]

class CommonQueryParams:
    def __init__(self, q: str | None = None, skip: int = 0, limit: int = 100):
        self.q = q
        self.skip = skip
        self.limit = limit

@app.get("/items/")
async def read_items(commons: Annotated[CommonQueryParams, Depends()]):
    response = {}
    if commons.q:
        response.update({"q": commons.q})
    items = fake_items_db[commons.skip : commons.skip + commons.limit]
    response.update({"items": items})
    return response
```

这只是减少重复的语法糖；若觉得更混乱，完全可以不用，仍写 `Depends(CommonQueryParams)`。

### 6. 易错点小结

- ✅ 类作依赖时，FastAPI 调用的是**类本身**（实例化），参数来自 `__init__`。
- ✅ 前一个类型注解只是给编辑器看的；真正生效的是 `Depends(...)` 里的可调用对象。
- ✅ 若省略 `Depends()` 的参数，则必须保证参数注解就是那个类。
- ✅ 用类实例替代 `dict`，获得类型补全与检查，同时校验与文档行为不变。

## 二、NestJS 对比

| 维度 | FastAPI（Python） | NestJS（TypeScript） |
|---|---|---|
| 依赖载体 | 可直接把「类」作为依赖：`Depends(CommonQueryParams)` | 类需加 `@Injectable()` 成为 Provider 并注册 |
| 实例化方式 | FastAPI 调用 `__init__`，把实例注入参数 | NestJS IoC 容器实例化 Provider 并构造器注入 |
| 参数来源 | `__init__` 的参数被当作请求参数自动提取 | 构造器参数按类型注入实例；请求数据靠 `@Query/@Body` |
| 类型信息 | 靠参数注解保留编辑器补全（`Annotated[CommonQueryParams, ...]`） | 靠 TypeScript 类型 + 装饰器元数据，编译期强类型 |
| 省重复写法 | `Depends()` 省略类名（依赖即参数类型） | 无对应写法，需 `@Inject()` 或令牌声明 |
| 文档与校验 | `__init__` 参数自动进 OpenAPI | Provider 不进文档；请求需 DTO + `class-validator` |
| 前置步骤 | 不需要注册、不需要基类 | 必须在 `@Module({ providers })` 注册 |

**核心差异一句话**：FastAPI 把类当成「带 `__init__` 的可调用对象」直接调用注入，零注册、零基类；NestJS 的类必须先加 `@Injectable()` 并在模块注册成 Provider，由容器管理实例与生命周期。

## 三、针对性练习题

### 题 1（基础）
定义一个类 `Pagination`，其 `__init__` 接收 `page: int = 1, size: int = 20`，并在 `GET /books/` 中用 `Depends(Pagination)` 注入实例后返回 `{"page": ..., "size": ...}`。

<details>
<summary>参考答案</summary>

```python
from typing import Annotated
from fastapi import Depends, FastAPI

app = FastAPI()

class Pagination:
    def __init__(self, page: int = 1, size: int = 20):
        self.page = page
        self.size = size

@app.get("/books/")
async def list_books(p: Annotated[Pagination, Depends(Pagination)]):
    return {"page": p.page, "size": p.size}
```

FastAPI 调用 `Pagination` 类创建实例并注入 `p`，`page/size` 作为查询参数被解析与校验。
</details>

### 题 2（理解）
为什么说「依赖项必须是可调用对象」？类为什么能作为依赖项？

<details>
<summary>参考答案</summary>

FastAPI 依赖机制的本质是：拿到一个能被调用的对象，分析其参数（按路径操作函数参数规则解析），在请求时调用并注入返回值。函数天然可调用；类也能用 `Class(...)` 语法「调用」来产生实例，所以类同样是可调用对象，能作为依赖。FastAPI 实际检查的是「可调用性 + 参数定义」，而非「是不是函数」。
</details>

### 题 3（辨析 / 代码）
下面两种注解有什么本质区别？

```python
# A
commons: Annotated[CommonQueryParams, Depends(CommonQueryParams)]
# B
commons: Annotated[Any, Depends(CommonQueryParams)]
```

<details>
<summary>参考答案</summary>

两者运行时都能工作，因为真正生效的是 `Depends(CommonQueryParams)`——FastAPI 从这里提取参数并调用类。区别在前半部分类型注解：A 把 `commons` 标注为 `CommonQueryParams`，编辑器能补全 `commons.q`、静态检查；B 标成 `Any`，编辑器失去类型信息。A 中前面的类型对 FastAPI 本身无特殊意义，但强烈建议保留。
</details>

### 题 4（进阶 · NestJS 迁移视角）
你原来在 NestJS 里这样写：

```ts
@Injectable()
class CommonQueryParams { /* ... */ }

@Controller()
export class ItemsController {
  @Get()
  read(@Query() q: CommonQueryParams) { /* ... */ }
}
```

请改写为等价的 FastAPI 代码，并说明「注册」步骤的差异。

<details>
<summary>参考答案</summary>

```python
from typing import Annotated
from fastapi import Depends, FastAPI

app = FastAPI()

class CommonQueryParams:
    def __init__(self, q: str | None = None, skip: int = 0, limit: int = 100):
        self.q, self.skip, self.limit = q, skip, limit

@app.get("/items/")
async def read_items(commons: Annotated[CommonQueryParams, Depends()]):
    return {"q": commons.q, "skip": commons.skip, "limit": commons.limit}
```

差异：NestJS 必须给类加 `@Injectable()` 并在 `@Module({providers:[...]})` 注册，才能由容器注入；FastAPI 无需任何注册或基类，直接把类传给 `Depends`（或用 `Depends()` 快捷写法）即可。
</details>

### 题 5（思考）
用类代替返回 `dict` 的依赖，主要收益是什么？`Depends()` 不带参数的快捷写法有何前提？

<details>
<summary>参考答案</summary>

收益：注入的是带明确类型的实例，编辑器能提供属性补全与类型检查（`dict` 则不知道键值类型），同时校验与 OpenAPI 文档行为不变。

`Depends()` 省略参数的前提：该依赖**明确是一个类**，且参数注解就是这个类——FastAPI 会把注解的类型当作要调用的类来实例化。若依赖是普通函数，则不能省略，必须写 `Depends(func)`。
</details>
