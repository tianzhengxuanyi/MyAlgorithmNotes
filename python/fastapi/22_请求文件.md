## 一、章节笔记

### 1. 本章要解决什么问题

上传文件本质上是**以表单数据发送**的，所以需要 `python-multipart`（`uv add python-multipart`）。本章学习用 `File`、`bytes`、`UploadFile` 接收文件，处理单文件、可选文件、多文件及元数据。

### 2. 导入 File 与 UploadFile

```python
from typing import Annotated

from fastapi import FastAPI, File, UploadFile

app = FastAPI()

@app.post("/files/")
async def create_file(file: Annotated[bytes, File()]):
    return {"file_size": len(file)}

@app.post("/uploadfile/")
async def create_upload_file(file: UploadFile):
    return {"filename": file.filename}
```

- 像声明 `Body`/`Form` 一样声明文件参数；必须用 `File` 标记，否则参数会被当作查询参数或 JSON 请求体。
- `File` 是**直接继承自 `Form`** 的类；从 `fastapi` 导入的 `File` 等实际上是返回特定类的函数。
- 类型为 `bytes` 时，FastAPI 读取整个文件内容为 `bytes` —— **全部内容存在内存中**，仅适合小文件。
- 类型为 `UploadFile` 时无需 `File()` 默认值即可声明，且适合大文件。

### 3. 为什么推荐 UploadFile

相比 `bytes`，`UploadFile` 的优势：

- 无需在参数默认值中使用 `File()`。
- 使用 **spooled 文件**：先存内存，达到上限后写入磁盘 —— 处理图像、视频、大型二进制文件时不会吃光内存。
- 可获取上传文件的**元数据**。
- 提供 **file-like 的 `async` 接口**。
- 暴露实际的 Python `SpooledTemporaryFile` 对象，可直接传给期望 file-like 对象的库。

### 4. UploadFile 的属性与方法

**属性**

| 属性 | 类型 | 说明 |
|---|---|---|
| `filename` | `str` | 上传的原始文件名，如 `myimage.jpg` |
| `content_type` | `str` | MIME 类型，如 `image/jpeg` |
| `file` | `SpooledTemporaryFile` | 实际文件对象，可直接传给其它库 |

**async 方法**（底层调用 `SpooledTemporaryFile` 的对应方法，需用 `await`）

| 方法 | 说明 |
|---|---|
| `write(data)` | 写入 `str` 或 `bytes` 数据 |
| `read(size)` | 读取 `size` 个字节/字符 |
| `seek(offset)` | 移动到指定字节位置，`await myfile.seek(0)` 回到开头（`read()` 后想再读时很有用） |
| `close()` | 关闭文件 |

```python
# async def 路径操作函数中
contents = await myfile.read()

# 普通 def 路径操作函数中，直接访问文件对象
contents = myfile.file.read()
```

- 使用 `async` 方法时，FastAPI 会在**线程池**中运行对应的文件方法并等待完成。
- FastAPI 的 `UploadFile` 直接继承自 Starlette 的 `UploadFile`，补充了与 Pydantic/FastAPI 兼容所需的部分。

### 5. 表单数据编码与限制

| 场景 | 编码 |
|---|---|
| 表单不含文件 | `application/x-www-form-urlencoded` |
| 表单含文件（`File`） | `multipart/form-data` |

- 使用 `File` 后 FastAPI 知道从请求体正确位置取文件。
- ⚠️ 可在一个路径操作中声明多个 `File` 和 `Form` 参数，但**不能同时声明 JSON `Body` 字段**：请求体用 `multipart/form-data` 编码而非 `application/json`。这是 HTTP 协议规定，不是 FastAPI 的限制。

### 6. 可选文件上传

```python
from typing import Annotated

from fastapi import FastAPI, File, UploadFile

app = FastAPI()

@app.post("/files/")
async def create_file(file: Annotated[bytes | None, File()] = None):
    if not file:
        return {"message": "No file sent"}
    return {"file_size": len(file)}

@app.post("/uploadfile/")
async def create_upload_file(file: UploadFile | None = None):
    if not file:
        return {"message": "No upload file sent"}
    return {"filename": file.filename}
```

用标准类型注解 `| None` + 默认值 `None` 即可让文件可选。

### 7. 带额外元数据的 UploadFile

`File()` 也能给 `UploadFile` 加元数据（如 `description`）：

```python
from typing import Annotated

from fastapi import FastAPI, File, UploadFile

app = FastAPI()

@app.post("/uploadfile/")
async def create_upload_file(
    file: Annotated[UploadFile, File(description="A file read as UploadFile")],
):
    return {"filename": file.filename}
```

### 8. 多文件上传

声明 `list[bytes]` 或 `list[UploadFile]` 即可接收同一表单字段下的多个文件：

```python
from typing import Annotated

from fastapi import FastAPI, File, UploadFile
from fastapi.responses import HTMLResponse

app = FastAPI()

@app.post("/files/")
async def create_files(files: Annotated[list[bytes], File()]):
    return {"file_sizes": [len(file) for file in files]}

@app.post("/uploadfiles/")
async def create_upload_files(files: list[UploadFile]):
    return {"filenames": [file.filename for file in files]}
```

多文件同样可用 `File(description=...)` 加元数据。技术细节：`fastapi.responses` 与 `starlette.responses` 相同（多数 FastAPI 响应直接来自 Starlette）。

### 9. 易错点

- ✅ 用 `bytes` 会把整个文件读进内存，大文件务必用 `UploadFile`。
- ✅ `UploadFile` 的读写方法是 `async`，在 `async def` 中必须 `await`；普通 `def` 中直接操作 `.file`。
- ✅ `read()` 之后再读要先 `seek(0)`。
- ✅ 文件与 JSON `Body` 不能混用（HTTP 编码限制）。

## 二、NestJS 对比

| 维度 | FastAPI（Python） | NestJS（TypeScript） |
|---|---|---|
| 声明上传文件 | `file: Annotated[bytes, File()]` 或 `file: UploadFile` | `@UploadedFile()` 参数装饰器 + `@UseInterceptors(FileInterceptor('field'))` |
| 大文件处理 | `UploadFile` 用 spooled 临时文件（内存超限转磁盘） | Multer 默认写磁盘/内存可配置（`storage: diskStorage / memoryStorage`） |
| 文件元数据 | `filename`、`content_type`、`file`（SpooledTemporaryFile） | `Express.Multer.File`：`originalname`、`mimetype`、`buffer`、`path` 等 |
| 多文件上传 | `list[UploadFile]` / `list[bytes]`，同一字段名多个文件 | `FilesInterceptor('files', maxCount)` + `@UploadedFiles()`，或 `AnyFilesInterceptor()` |
| 可选文件 | `file: UploadFile | None = None` | `@Optional() @UploadedFile()` + 手动判空 |
| 解析依赖 | `python-multipart`（`uv add python-multipart`） | `@nestjs/platform-express` 自带 multer；Fastify 适配器需 `@fastify/multipart` |
| 与表单字段混用 | `File` + `Form` 可共存，请求体为 `multipart/form-data` | `FileInterceptor` + `@Body()` 共存，需同一 multipart 请求 |
| 异步读取 | `await file.read()` / `seek()` / `close()`，底层走线程池 | `buffer` 同步可读；流式处理需 Readable stream + 手动管线 |
| 与 JSON 混用 | 禁止：multipart 与 application/json 不能共存 | 同样受 HTTP 协议限制 |

**核心差异一句话**：FastAPI 用参数类型本身区分「小文件 `bytes`」与「大文件 `UploadFile`」，后者自带 spooled 存储、元数据与 async 文件接口，无需拦截器样板；NestJS 必须通过 `FileInterceptor`/`FilesInterceptor` + `@UploadedFile()` 显式接线，上传细节由 Multer 配置掌控，更可配置但代码更多。

## 三、针对性练习题

### 题 1（基础）

写两个端点：`POST /files/` 用 `bytes` 接收小文件并返回大小；`POST /uploadfile/` 用 `UploadFile` 返回文件名。并说明运行前置依赖。

<details>
<summary>参考答案</summary>

```python
from typing import Annotated
from fastapi import FastAPI, File, UploadFile

app = FastAPI()

@app.post("/files/")
async def create_file(file: Annotated[bytes, File()]):
    return {"file_size": len(file)}

@app.post("/uploadfile/")
async def create_upload_file(file: UploadFile):
    return {"filename": file.filename}
```

前置依赖：`uv add python-multipart`，因为文件以表单数据上传。
</details>

### 题 2（理解）

为什么处理大文件应该用 `UploadFile` 而不是 `bytes`？列出至少三点优势。

<details>
<summary>参考答案</summary>

`bytes` 会把整个文件内容读入内存，大文件会耗尽内存。`UploadFile` 的优势：① 使用 spooled 文件（先内存、超限写磁盘），适合大文件；② 可获取元数据（`filename`、`content_type`）；③ 提供 file-like 的 async 接口；④ 暴露 `SpooledTemporaryFile` 可直接传给其它库；⑤ 无需写 `File()` 默认值。
</details>

### 题 3（代码/辨析）

下面的 `UploadFile` 读取代码有什么问题？如何修正？

```python
@app.post("/uploadfile/")
async def create_upload_file(file: UploadFile):
    first = await file.read()
    second = await file.read()
    return {"first": first, "second": second}
```

<details>
<summary>参考答案</summary>

第一次 `read()` 后文件指针已到末尾，第二次 `read()` 返回空字节。修正：第二次读取前用 `seek(0)` 回到开头：

```python
@app.post("/uploadfile/")
async def create_upload_file(file: UploadFile):
    first = await file.read()
    await file.seek(0)
    second = await file.read()
    return {"first": first, "second": second}
```

`read()`/`seek()`/`write()`/`close()` 都是 async 方法，在 `async def` 中必须 `await`。
</details>

### 题 4（进阶 · NestJS 迁移视角）

NestJS 中你这样接收多个文件：

```ts
@Post('uploadfiles')
@UseInterceptors(FilesInterceptor('files', 10))
upload(@UploadedFiles() files: Express.Multer.File[]) {
  return { names: files.map(f => f.originalname) };
}
```

写出等价的 FastAPI 代码，并说明「多文件」与「元数据」映射的差异。

<details>
<summary>参考答案</summary>

```python
from fastapi import FastAPI, File, UploadFile

app = FastAPI()

@app.post("/uploadfiles/")
async def upload(files: list[UploadFile]):
    return {"names": [file.filename for file in files]}
```

差异：FastAPI 用 `list[UploadFile]` 类型声明即表示同名字段下的多文件，无需拦截器；元数据通过 `file.filename` / `file.content_type` 获取。NestJS 需 `FilesInterceptor('files', 10)` 指定字段名和数量上限，元数据来自 Multer 的 `Express.Multer.File`（`originalname`、`mimetype`、`buffer`/`path`）。
</details>

### 题 5（思考）

一个端点想同时接收 `token: Form()` 表单字段、`avatar: UploadFile` 文件和 `payload: dict = Body(...)` JSON 请求体。可行吗？如果不行，HTTP 层面原因是什么？

<details>
<summary>参考答案</summary>

不可行。含文件的表单请求体编码为 `multipart/form-data`，而 JSON `Body` 要求 `application/json`，一个 HTTP 请求体只能使用一种编码。这不是 FastAPI 的限制，而是 HTTP 协议规定。`Form` + `File` 共存没问题（都属 multipart），但 JSON `Body` 必须去掉，把数据也放进表单字段。
</details>
