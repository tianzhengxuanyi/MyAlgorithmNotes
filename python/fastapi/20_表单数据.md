## 一、章节笔记

### 1. 本章要解决什么问题

HTML 表单提交的数据不是 JSON，而是用**特殊编码**（`application/x-www-form-urlencoded`）发送的键值对。本章学习用 `Form` 声明表单字段，让 FastAPI 从正确的位置读取它们（典型场景：OAuth2 密码流要求 `username`、`password` 作为表单字段发送）。

> 📦 前置安装：`uv add python-multipart`（解析表单/上传文件必需）。

### 2. 导入并声明 Form 参数

```python
from typing import Annotated

from fastapi import FastAPI, Form

app = FastAPI()

@app.post("/login/")
async def login(username: Annotated[str, Form()], password: Annotated[str, Form()]):
    return {"username": username}
```

- 从 `fastapi` 导入 `Form`，用 `Annotated[..., Form()]` 标记。
- 创建表单参数的方式与 `Body`、`Query` 完全相同：可声明校验、示例、别名（如把 `username` 别名成 `user-name`）等。
- 非 `Annotated` 等价写法：`username: str = Form(), password: str = Form()`。

> ⚠️ 必须显式使用 `Form`，否则参数会被当作**查询参数或 JSON 请求体**参数。
>
> 技术细节：`Form` 是**直接继承自 `Body`** 的类。

### 3. 布尔表单字段（复选框）

浏览器提交 HTML 表单时会**忽略未选中的复选框**。解决办法：把布尔字段默认值声明为 `False`。

```python
from typing import Annotated

from fastapi import FastAPI, Form

app = FastAPI()

@app.post("/preferences/")
async def update_preferences(subscribe: Annotated[bool, Form()] = False):
    return {"subscribe": subscribe}
```

- 未勾选 → 字段缺失 → 得到默认值 `False`。
- 勾选 → 浏览器发送其值，默认为 `"on"`，FastAPI 会把 `"on"` 解析为 `True`。

### 4. 编码方式与限制

| 场景 | 媒体类型 | 说明 |
|---|---|---|
| 普通表单（无文件） | `application/x-www-form-urlencoded` | HTML 表单默认编码 |
| 含文件的表单 | `multipart/form-data` | 下一章「请求文件」处理 |

- 想让 OpenAPI 把表单描述为多部分表单，使用 `Form(media_type="multipart/form-data")`；组合表单参数/模型时，**只需在一个参数上设置**即可。
- ⚠️ 一个路径操作中可以声明多个 `Form` 参数，但**不能同时声明接收 JSON 的 `Body` 字段**：此时请求体用 `application/x-www-form-urlencoded` 编码，而不是 `application/json`。这不是 FastAPI 的限制，而是 HTTP 协议的规定。

### 5. 易错点

- ✅ 忘记 `Form()` → 参数从查询串或 JSON 请求体取值，表单提交时拿到 422。
- ✅ 未安装 `python-multipart` → 使用表单时报错。
- ✅ 复选框默认值设为 `False`，否则未勾选时字段缺失会报错。
- ✅ JSON `Body` 与 `Form` 不能混用（HTTP 请求体只能有一种编码）。

## 二、NestJS 对比

| 维度 | FastAPI（Python） | NestJS（TypeScript） |
|---|---|---|
| 声明表单字段 | 参数注解 `Annotated[str, Form()]`，逐字段标记 | 没有 `@Form()`；用 `@Body('username')` 取字段，或 `@Body() dto: Dto` 绑定整个对象 |
| 编码解析 | FastAPI 基于 `python-multipart` 自动按媒体类型解析 | 底层 Express/Fastify 的 `body-parser` 解析 `application/x-www-form-urlencoded`；Fastify 需 `@fastify/formbody` |
| 字段校验 | `Form()` 复用 `Body` 的全部校验/别名/示例能力，基于类型注解 | DTO + `class-validator` 装饰器 + `ValidationPipe` |
| 布尔复选框 | 默认值 `False`；`"on"` 自动解析为 `True` | 需 DTO 中 `@IsBoolean()` + `Transform` 把 `"on"` 转成布尔 |
| 混用 JSON | 禁止：`Form` 与 JSON `Body` 不能共存（HTTP 协议限制） | 同样受限于请求体编码；`multipart/form-data` 时用 `FileInterceptor`/`AnyFilesInterceptor` + `@Body()` 组合 |
| 别名映射 | `Form(alias="user-name")` 直接声明 | `@Body('user-name')` 显式取键名 |
| 多部分表单标注 | `Form(media_type="multipart/form-data")` 写入 OpenAPI | `@nestjs/swagger` 需 `@ApiBody` / `@ApiConsumes('multipart/form-data')` |
| OAuth2 密码流 | `username`/`password` 直接声明为 `Form()`，安全章节复用 | 通常用 `passport` 策略 + `@Body()` DTO 或自定义 Guard |

**核心差异一句话**：FastAPI 用 `Form()` 把表单字段当作一等参数，与 `Body`/`Query` 共享同一套基于类型注解的校验和文档能力，且自动处理 `"on"`→`True` 的复选框语义；NestJS 没有专门的 `@Form()`，表单键通过 `@Body('key')` 或 DTO 绑定获取，编码解析依赖底层 HTTP 适配器，`"on"` 之类转换要自己写 `Transform`。

## 三、针对性练习题

### 题 1（基础）

写一个 `POST /login/` 端点，用表单接收 `username` 与 `password`，只返回 `username`。并指出运行前需安装什么。

<details>
<summary>参考答案</summary>

```python
from typing import Annotated
from fastapi import FastAPI, Form

app = FastAPI()

@app.post("/login/")
async def login(username: Annotated[str, Form()], password: Annotated[str, Form()]):
    return {"username": username}
```

需先安装解析依赖：`uv add python-multipart`。
</details>

### 题 2（理解）

为什么 OAuth2「密码流」必须用 `Form` 声明 `username`、`password`，而不能用 JSON 请求体？

<details>
<summary>参考答案</summary>

OAuth2 密码流规范明确要求把 `username` 和 `password` 作为**表单字段**发送，且字段名必须精确为 `username`、`password`，不是 JSON。FastAPI 用 `Form()` 标记后才能从 `application/x-www-form-urlencoded` 请求体中读取；若用 JSON `Body` 参数，规范兼容的客户端提交的表单数据不会被正确解析。
</details>

### 题 3（辨析/代码）

下面代码想接收一个可勾选的订阅选项。未勾选和勾选时分别得到什么值？为什么要把默认值设为 `False`？

```python
@app.post("/preferences/")
async def update_preferences(subscribe: Annotated[bool, Form()] = False):
    return {"subscribe": subscribe}
```

<details>
<summary>参考答案</summary>

- 未勾选：浏览器**不发送**该字段，FastAPI 使用默认值 `False`。
- 勾选：浏览器发送值（默认 `"on"`），FastAPI 解析为 `True`。

若不设默认值 `False`，未勾选时字段缺失会导致 422 校验错误；设为 `False` 才能正确表达复选框「关」的语义。
</details>

### 题 4（进阶 · NestJS 迁移视角）

NestJS 中你这样写：

```ts
@Post('login')
login(@Body('username') username: string, @Body('password') password: string) {
  return { username };
}
```

请写出等价的 FastAPI 代码，并说明「表单字段声明」上的主要差异。

<details>
<summary>参考答案</summary>

```python
from typing import Annotated
from fastapi import FastAPI, Form

app = FastAPI()

@app.post("/login/")
async def login(username: Annotated[str, Form()], password: Annotated[str, Form()]):
    return {"username": username}
```

差异：NestJS 用 `@Body('username')` 从解析后的 body 对象按键取值（无专门的表单装饰器）；FastAPI 用 `Form()` 明确标记字段来自表单编码的请求体，且参数类型注解本身承担校验与 OpenAPI 文档生成，无需 DTO + `class-validator` 装饰器。
</details>

### 题 5（思考）

一个端点已经声明了 `token: Annotated[str, Form()]`，现在想再加一个 JSON 请求体参数 `payload: dict = Body(...)`。可行吗？为什么？

<details>
<summary>参考答案</summary>

不可行。声明了 `Form` 参数后，请求体按 `application/x-www-form-urlencoded`（或含文件时的 `multipart/form-data`）编码，而 JSON `Body` 要求 `application/json`，一个 HTTP 请求体只能有一种编码。这是 HTTP 协议层面的限制，不是 FastAPI 的限制。解决办法：统一用表单字段（可拆成多个 `Form` 或表单模型），或统一用 JSON，二者不可混用。
</details>
