## 一、章节笔记

### 1. 什么是查询参数

路径操作函数中，**没有在路径里声明的参数**会被自动解释为"查询参数"（Query Parameter）。

```python
from fastapi import FastAPI

app = FastAPI()

fake_items_db = [{"item_name": "Foo"}, {"item_name": "Bar"}, {"item_name": "Baz"}]

@app.get("/items/")
async def read_item(skip: int = 0, limit: int = 10):
    return fake_items_db[skip : skip + limit]
```

查询字符串是 URL 中 `?` 之后、以 `&` 分隔的键值对集合。例如：

```
http://127.0.0.1:8000/items/?skip=0&limit=10
```

其中 `skip=0`、`limit=10` 就是查询参数。它们在 URL 中本是字符串，但声明 Python 类型（上例 `int`）后，会自动**转换为声明类型并校验**。

### 2. 与路径参数共享的处理流程

所有应用于路径参数的流程同样适用于查询参数：

- 编辑器支持（类型检查、补全）
- 数据"解析"（字符串 → 目标类型）
- 数据校验（非法值返回 422）
- 自动文档

区别仅在于：路径参数来自 URL 路径段且必填；查询参数来自 `?` 后的键值对，可带默认值/可选。

### 3. 默认值

查询参数可以有默认值，因此是可选的：

```python
@app.get("/items/")
async def read_item(skip: int = 0, limit: int = 10):
    return fake_items_db[skip : skip + limit]
```

| 请求 URL | skip | limit | 说明 |
|---|---|---|---|
| `/items/` | 0 | 10 | 两者均用默认值 |
| `/items/?skip=0&limit=10` | 0 | 10 | 显式传入，等价 |
| `/items/?skip=20` | 20 | 10 | skip 用传入值，limit 用默认值 |

### 4. 可选参数（`= None`）

把默认值设为 `None` 即可声明可选查询参数：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/{item_id}")
async def read_item(item_id: str, q: str | None = None):
    if q:
        return {"item_id": item_id, "q": q}
    return {"item_id": item_id}
```

FastAPI 能识别：`item_id` 与路径中的 `{item_id}` 匹配 → 路径参数；`q` 不在路径中 → 查询参数。

### 5. 类型转换：`bool` 参数

查询参数可声明为 `bool`，FastAPI 自动做布尔转换：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/{item_id}")
async def read_item(item_id: str, q: str | None = None, short: bool = False):
    item = {"item_id": item_id}
    if q:
        item.update({"q": q})
    if not short:
        item.update(
            {"description": "This is an amazing item that has a long description"}
        )
    return item
```

`short` 的取值规则：

| 传入值（含任意大小写变体） | 转换结果 |
|---|---|
| `1` / `True` / `true` / `on` / `yes` | `True` |
| `0` / `false` / `off` / `no` | `False` |
| 省略 | 使用默认值 `False` |
| 空值 `?short=` / 无法识别如 `?short=maybe` | `422` 校验错误 |

### 6. 多个路径参数 + 查询参数

FastAPI 可识别同时声明的多个路径参数与查询参数，**声明顺序无关**，通过参数名检测：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/users/{user_id}/items/{item_id}")
async def read_user_item(
    user_id: int, item_id: str, q: str | None = None, short: bool = False
):
    item = {"item_id": item_id, "owner_id": user_id}
    if q:
        item.update({"q": q})
    if not short:
        item.update(
            {"description": "This is an amazing item that has a long description"}
        )
    return item
```

### 7. 必选查询参数

**不声明默认值**即成为必选查询参数：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/{item_id}")
async def read_user_item(item_id: str, needy: str):
    item = {"item_id": item_id, "needy": needy}
    return item
```

访问 `/items/foo-item`（缺少 `needy`）返回 `422`：

```json
{
  "detail": [
    {
      "type": "missing",
      "loc": ["query", "needy"],
      "msg": "Field required",
      "input": null
    }
  ]
}
```

访问 `/items/foo-item?needy=sooooneedy` 则正常返回 `{"item_id":"foo-item","needy":"sooooneedy"}`。

三种类型可自由混用：

```python
@app.get("/items/{item_id}")
async def read_user_item(
    item_id: str, needy: str, skip: int = 0, limit: int | None = None
):
    item = {"item_id": item_id, "needy": needy, "skip": skip, "limit": limit}
    return item
```

本例中有 3 个查询参数：`needy` 必选 `str`、`skip` 默认 `0` 的 `int`、`limit` 可选 `int`。

### 8. 易错点小结

- ✅ 是否必选由**是否有默认值**决定，而非类型是否含 `None`。`q: str | None = None` 可选；`needy: str` 必选。
- ✅ `bool` 参数自动识别多种真/假字面量，但空串与无法识别的值会 `422`。
- ✅ 路径参数与查询参数靠**参数名**区分，顺序不影响解析。
- ✅ 查询参数同样支持 `Enum` 来限定可选值（写法与路径参数一致）。

## 二、NestJS 对比

| 维度 | FastAPI（Python） | NestJS（TypeScript） |
|---|---|---|
| 参数获取 | 函数签名中非路径参数自动识别为查询参数，无需装饰器 | 必须用 `@Query()` / `@Query('key')` 装饰器显式取出 |
| 类型转换 | 靠类型注解 `skip: int`、`short: bool` 自动转换 | 默认拿到 `string`，需 `ParseIntPipe`、`ParseBoolPipe` 等管道转换 |
| 默认值 / 可选 | 用函数默认值 `skip: int = 0`、`q: str | None = None` | 在 DTO 中用 `@IsOptional()` + 默认值，或 handler 内取默认值 |
| 必选参数 | 不写默认值即必选，缺失返回 `422` | DTO 字段无 `@IsOptional()` 则由 `ValidationPipe` 判缺失 |
| 布尔真值识别 | 内建识别 `1/true/on/yes` 与 `0/false/off/no`（大小写不敏感） | 需 `ParseBoolPipe` 或 `class-transformer` 的 `@Transform` 实现 |
| 参数来源判定 | 按**名称**与路径模板比对，自动区分 path/query | 由不同装饰器 `@Param` / `@Query` 显式声明来源 |
| 校验错误格式 | Pydantic 统一返回 `422` + `loc/type/msg` | `ValidationPipe` 抛出 `BadRequestException`（400），格式需自定义 |
| 文档体现 | 类型与默认值自动进入 OpenAPI，`/docs` 可试填 | 需 `@nestjs/swagger` 的 `@ApiQuery()` 与 DTO 的 `@ApiProperty()` 补充 |

**核心差异一句话**：FastAPI 让"函数签名即参数契约"——不写装饰器，靠类型注解与默认值就完成查询参数的识别、转换、可选性与文档；NestJS 则通过 `@Query` 取参、`Parse*Pipe` 转换、`ValidationPipe` 校验，把每一环显式拆成可替换的管道。

## 三、针对性练习题

### 题 1（基础）

写 `GET /items/`，接收 `skip: int = 0` 与 `limit: int = 10` 两个查询参数，返回列表切片 `fake_items_db[skip:skip+limit]`。说明 `/items/?skip=20` 时两个参数各取什么值。

<details>
<summary>参考答案</summary>

```python
from fastapi import FastAPI
app = FastAPI()
fake_items_db = [{"item_name": "Foo"}, {"item_name": "Bar"}, {"item_name": "Baz"}]

@app.get("/items/")
async def read_item(skip: int = 0, limit: int = 10):
    return fake_items_db[skip : skip + limit]
```

`/items/?skip=20`：skip 取 URL 中的 `20`，limit 使用默认值 `10`，返回 `fake_items_db[20:30]`（空列表）。
</details>

### 题 2（理解）

`q: str | None = None` 与 `needy: str` 都是非路径参数，为什么前者可选而后者必选？判断"必填与否"的依据到底是什么？

<details>
<summary>参考答案</summary>

判断依据是**是否声明了默认值**，而不是类型里是否含 `None`。`q: str | None = None` 有默认值 `None`，因此可选；`needy: str` 没有默认值，因此必选，缺失时返回 `422`（`type: missing`，`loc: ["query","needy"]`）。类型注解中的 `| None` 主要服务于编辑器类型检查与补全，让函数体内能安全处理空值。
</details>

### 题 3（辨析/代码）

对 `short: bool = False`，以下 URL 分别得到什么结果？哪些会返回 `422`？

`/items/foo?short=1`、`/items/foo?short=on`、`/items/foo?short=maybe`、`/items/foo?short=`

<details>
<summary>参考答案</summary>

- `?short=1` → `True`（`1/True/true/on/yes` 及大小写变体均为 True）
- `?short=on` → `True`
- `?short=maybe` → `422` 校验错误（无法识别的布尔值）
- `?short=` → `422` 校验错误（空值无法解析为 bool）

省略 `short` 则使用默认值 `False`。
</details>

### 题 4（进阶 · NestJS 迁移视角）

NestJS 中你这样写：

```ts
@Get('items')
findAll(@Query('skip') skip = 0, @Query('limit') limit = 10) {
  return this.service.find(skip, limit);
}
```

请写出等价的 FastAPI 版本，并指出 NestJS 的 `@Query('skip')` 与默认值在 FastAPI 中分别对应什么。

<details>
<summary>参考答案</summary>

```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/items/")
async def find_all(skip: int = 0, limit: int = 10):
    return {"skip": skip, "limit": limit}
```

对应关系：
- `@Query('skip')` 的参数取值，在 FastAPI 中由**函数参数名 `skip`** 自动完成，无需装饰器。
- NestJS 里 `skip = 0` 的默认值在 FastAPI 中同样是 `skip: int = 0`；额外的 `int` 注解还带来自动类型转换与校验，相当于 NestJS 中额外加了 `ParseIntPipe`。
</details>

### 题 5（思考）

有人说"FastAPI 里函数参数的顺序会影响参数解析，必须把路径参数写在前面"。这句话对吗？请结合路径参数与查询参数的识别机制说明。

<details>
<summary>参考答案</summary>

不对。FastAPI 通过**参数名**与路径模板比对来判定来源：名字出现在路径 `{}` 中的是路径参数，其余的是查询参数，与声明顺序无关。例如 `@app.get("/users/{user_id}/items/{item_id}")` 的函数可写成 `async def read_user_item(q: str | None = None, user_id: int, item_id: str)` 仍能正确识别。（唯一与"顺序"有关的是**路由声明顺序**：固定路径要写在动态路径之前，那是路径匹配的顺序，而非函数参数顺序。）
</details>
