# 42 · 更大的应用 - 多个文件（Bigger Applications - Multiple Files）

> 官方文档：<https://fastapi.tiangolo.com/zh/tutorial/bigger-applications/>
> 前置依赖：路径操作、Depends 依赖注入 · 难度：⭐⭐

---

## 一、章节笔记

### 1. 本章要解决什么问题

真实项目很少把所有代码放一个文件。FastAPI 提供 `APIRouter` 把路径操作拆分到多个模块，同时保持所有灵活性（相当于 Flask 的 Blueprints）。所有子模块共享同一个 FastAPI 应用、同一份 OpenAPI 文档。

### 2. 典型文件结构

```text
.
├── app
│   ├── __init__.py          # 使 app 成为 Python 包
│   ├── main.py              # 主应用 app.main
│   ├── dependencies.py      # 共享依赖 app.dependencies
│   ├── routers
│   │   ├── __init__.py      # 子包 app.routers
│   │   ├── items.py         # 子模块 app.routers.items
│   │   └── users.py         # 子模块 app.routers.users
│   └── internal
│       ├── __init__.py      # 子包 app.internal
│       └── admin.py         # 子模块 app.internal.admin
```

关键点：每个目录都有 `__init__.py`，这样目录才是 Python 包，才能用 `from app.routers import items` 这类导入。

### 3. `APIRouter`：迷你版 FastAPI

```python
from fastapi import APIRouter

router = APIRouter()

@router.get("/users/", tags=["users"])
async def read_users():
    return [{"username": "Rick"}, {"username": "Morty"}]

@router.get("/users/me", tags=["users"])
async def read_user_me():
    return {"username": "fakecurrentuser"}

@router.get("/users/{username}", tags=["users"])
async def read_user(username: str):
    return {"username": username}
```

- `APIRouter` 可以看作"迷你 FastAPI"：所有 `parameters`、`responses`、`dependencies`、`tags` 等选项都支持。
- 变量名不必叫 `router`，但惯例如此。

### 4. 共享依赖抽到 `dependencies.py`

```python
from typing import Annotated
from fastapi import Header, HTTPException

async def get_token_header(x_token: Annotated[str, Header()]):
    if x_token != "fake-super-secret-token":
        raise HTTPException(status_code=400, detail="X-Token header invalid")

async def get_query_token(token: str):
    if token != "jessica":
        raise HTTPException(status_code=400, detail="No Jessica token provided")
```

实践中应使用集成的安全工具而非自定义头部令牌；这里仅为演示。

### 5. 在 router 级别配置公共参数

业务上若一个模块的所有路径操作共享 `prefix`、`tags`、`responses`、`dependencies`，应写在 `APIRouter(...)` 上，避免逐条重复：

```python
from fastapi import APIRouter, Depends, HTTPException
from ..dependencies import get_token_header

router = APIRouter(
    prefix="/items",
    tags=["items"],
    dependencies=[Depends(get_token_header)],
    responses={404: {"description": "Not found"}},
)

fake_items_db = {"plumbus": {"name": "Plumbus"}, "gun": {"name": "Portal Gun"}}

@router.get("/")
async def read_items():
    return fake_items_db

@router.get("/{item_id}")
async def read_item(item_id: str):
    if item_id not in fake_items_db:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"name": fake_items_db[item_id]["name"], "item_id": item_id}

@router.put(
    "/{item_id}",
    tags=["custom"],
    responses={403: {"description": "Operation forbidden"}},
)
async def update_item(item_id: str):
    if item_id != "plumbus":
        raise HTTPException(status_code=403, detail="You can only update the item: plumbus")
    return {"item_id": item_id, "name": "The great Plumbus"}
```

| 规则/细节 | 说明 |
|---|---|
| `prefix="/items"` | 前缀**不能以 `/` 结尾**（路径本身必须以 `/` 开头） |
| 路径组合 | `"/"` → `/items/`，`"/{item_id}"` → `/items/{item_id}` |
| 标签组合 | 具体路径操作再声明 `tags=["custom"]`，最终标签为 `["items", "custom"]` |
| 响应组合 | 装饰器上再加 403，文档中同时有 404 和 403 |
| 依赖执行顺序 | router 的 dependencies → 装饰器的 dependencies → 普通参数依赖 |
| 依赖不传值 | router 级依赖的返回值不会传给路径操作函数 |
| 也可加 `Security(..., scopes=...)` | 用作用域保护整组接口 |

### 6. 相对导入

在 `app/routers/items.py` 中要用 `..` 回到父包 `app` 找 `dependencies.py`：

| 写法 | 含义 |
|---|---|
| `from .dependencies import get_token_header` | 当前包 `app/routers/` 下的 `dependencies.py`（本例不存在） |
| `from ..dependencies import get_token_header` | 父包 `app/` 下的 `dependencies.py`（本例正确） |
| `from ...dependencies import get_token_header` | 再上一级，超出顶层包，本例会报错 |

主文件 `app/main.py` 里用单个 `.`：`from .routers import items, users`。等价绝对导入：`from app.routers import items, users`。

### 7. 主文件 `app/main.py`：装配一切

```python
from fastapi import Depends, FastAPI

from .dependencies import get_query_token, get_token_header
from .internal import admin
from .routers import items, users

app = FastAPI(dependencies=[Depends(get_query_token)])

app.include_router(users.router)
app.include_router(items.router)
app.include_router(
    admin.router,
    prefix="/admin",
    tags=["admin"],
    dependencies=[Depends(get_token_header)],
    responses={418: {"description": "I'm a teapot"}},
)

@app.get("/")
async def root():
    return {"message": "Hello Bigger Applications!"}
```

- 全局依赖 `FastAPI(dependencies=[...])` 会与每个 router 的依赖组合。
- **`include_router()` 时可覆盖/追加元数据**：即使 `admin.py` 是不可修改的共享文件，也能在包含时加 `prefix`、`tags`、`dependencies`、`responses`，且只影响本项目，不影响其他复用该 router 的项目。
- 直接导入 `items`、`users` 模块而非只导入 `router` 变量，是为了避免两个模块中同名的 `router` 互相覆盖：

```python
# 错误：users 的 router 会覆盖 items 的
from .routers.items import router
from .routers.users import router
```

- 也可在路径操作之外直接 `@app.get("/")` 添加路由，与 router 中路由一起正常工作。
- 技术细节：`APIRouter` **不是"挂载"**，不隔离；FastAPI 保留原始 router/route 处于"活动"状态，组合前缀、依赖、标签等用于路由与 OpenAPI。包含 router 是轻量操作，不增加请求开销。
- 避免在包含后直接改 `router.routes`；用装饰器和 `.include_router()` 这些文档化 API。

### 8. 配置 entrypoint 与运行

```toml
[tool.fastapi]
entrypoint = "app.main:app"
```

运行：`uv run fastapi dev`，文档仍在 `/docs`。也可 `uv run fastapi dev app/main.py`，但每次都要传路径，且 VS Code 扩展、FastAPI Cloud 等工具可能找不到应用，故推荐 entrypoint。

### 9. 高级用法

- **同一 router 多次包含，用不同 prefix**：例如同时以 `/api/v1` 和 `/api/latest` 暴露同一组 API。
- **router 包含 router**：`router.include_router(other_router)`，可在主应用包含之前或之后调用，路径都会被纳入；之后加入的路径操作同样可见。

### 10. 易错点

| 易错点 | 正确做法 |
|---|---|
| 目录漏了 `__init__.py` | 每个子目录都要有，否则无法作为包导入 |
| `prefix="/items/"` 结尾带斜杠 | 前缀末尾不要 `/`，路径本身以 `/` 开头 |
| `from .routers.items import router` 连续导入两个 | 改为导入模块 `from .routers import items, users` |
| 以为 include 后 router 被复制/隔离 | 它是"活动"引用，修改原始 router 仍会影响应用 |
| 每次命令行传 main 路径 | 在 `pyproject.toml` 配置 `entrypoint` |

## 二、NestJS 对比

| 维度 | FastAPI（Python） | NestJS（TypeScript） |
|---|---|---|
| 分文件机制 | `APIRouter()` 实例 + `app.include_router()` | `@Controller()` 类 + `module` 的 `controllers` 数组注册 |
| 组织单位 | 函数路径操作（router 只是"迷你 FastAPI"） | Controller 类 + handler 方法 |
| 公共前缀 | `APIRouter(prefix="/items")` 或 `include_router(..., prefix=...)` | `@Controller('items')` 类级路径前缀 |
| 公共依赖 | `APIRouter(dependencies=[Depends(...)])`，整组路由生效 | `@UseGuards()` / `@UseInterceptors()` / 全局 Pipe、Middleware |
| 公共响应文档 | `APIRouter(responses={404: ...})` | `@ApiResponse()` 装饰器或 Swagger 插件 |
| 参数/校验元数据 | router 与路径操作都支持 `tags`、`responses`、`dependencies` | 装饰器 `@Get/@Post/@Param/@Query/@Body` + DTO 校验 |
| 依赖管理文件 | `dependencies.py` 模块，用 `Depends` 引用 | Provider 定义在 Module 的 `providers`，通过构造函数注入 |
| 模块系统 | 无 Module 概念，靠 Python 包/导入组织 | 强制 `Module → Controller → Provider`，`@Module()` 装配 |
| 共享不可改代码 | 用 `include_router(..., prefix/tags/dependencies=...)` 追加配置，不修改原文件 | 用动态 Module / 包装 Controller，或共享库模块导出 Provider |
| 文档合并 | 所有 router 自动合并到同一 OpenAPI | `@nestjs/swagger` 汇总各模块装饰器的元数据 |

**核心差异一句话**：FastAPI 的 `APIRouter` 是无状态的"路由集合"，靠 `include_router()` 时传入的参数灵活拼装前缀/依赖/标签，连第三方共享 router 不改源码就能定制；NestJS 的分文件以 Module 为强边界，Controller 和 Provider 必须通过模块显式注册，配置更倾向于写在类装饰器上而非装配处。

## 三、针对性练习题

### 题 1（基础）
为什么每个目录都要有 `__init__.py`？在 `app/routers/items.py` 中导入 `app/dependencies.py` 里的函数应写什么导入语句？

<details>
<summary>参考答案</summary>

`__init__.py` 让目录成为 Python 包，从而可被其他模块用点号路径导入（如 `from app.routers import items`）。`items.py` 位于 `app/routers/`，`dependencies.py` 位于父包 `app/`，因此要向上跳一级：`from ..dependencies import get_token_header`。（单点 `.` 指当前包，两点 `..` 指父包。）
</details>

### 题 2（理解）
`APIRouter(prefix="/items", dependencies=[Depends(get_token_header)])` 中配置的 prefix 和 dependencies 分别有什么效果？prefix 为什么不能写成 `/items/`？

<details>
<summary>参考答案</summary>

- `prefix` 会自动加在该 router 内所有路径操作前面：`"/"` → `/items/`、`"/{item_id}"` → `/items/{item_id}`。
- `dependencies` 会在该 router 每个路径操作执行前运行（即使具体路径操作自己没有声明），常用于整组接口的认证；其返回值不会传给路径操作函数。
- 每个路径必须以 `/` 开头，若 prefix 以 `/` 结尾会产生 `//` 双斜杠，因此 prefix 末尾不能加 `/`。
</details>

### 题 3（辨析/代码）
下面代码有什么问题？如何修正？

```python
from .routers.items import router
from .routers.users import router

app.include_router(router)
```

<details>
<summary>参考答案</summary>

两个模块都有名为 `router` 的变量，第二次导入会覆盖第一次，`items` 的路由丢失。修正为导入模块本身：

```python
from .routers import items, users

app.include_router(items.router)
app.include_router(users.router)
```

这样通过模块名限定变量，避免命名冲突。
</details>

### 题 4（进阶 · NestJS 迁移视角）
组织给你一个不可修改的共享文件 `app/internal/admin.py`，里面是普通 `router = APIRouter()` 加一个 `@router.post("/")`。你需要在本项目里给它加 `/admin` 前缀、`admin` 标签和 token 校验。写出做法并说明为什么不用改原文件。

<details>
<summary>参考答案</summary>

```python
app.include_router(
    admin.router,
    prefix="/admin",
    tags=["admin"],
    dependencies=[Depends(get_token_header)],
    responses={418: {"description": "I'm a teapot"}},
)
```

`include_router()` 接受 `prefix`、`tags`、`dependencies`、`responses` 参数，FastAPI 在包含时把这些元数据应用到该 router，原始 `APIRouter` 保持不变，因此共享文件仍可被其他项目复用，且各项目可用不同认证方式。NestJS 中类似需求通常要写包装 Controller 或动态 Module，不如这里在装配处直接配置简便。
</details>

### 题 5（思考）
为什么说 "`APIRouter` 不是挂载（mount）"？这对修改已包含的 router 意味着什么？

<details>
<summary>参考答案</summary>

挂载（如 `app.mount("/static", StaticFiles(...))`）会创建一个完全独立的子应用，主应用的 OpenAPI 与文档不包含它；而 `APIRouter` 被包含后，FastAPI 保留原始 router 和 APIRoute 处于"活动"状态，组合其前缀、依赖、标签等用于路由与 OpenAPI 生成。因此：
① 所有路由都会出现在同一份文档里；
② 包含之后继续向原 router 添加路径操作，也会被应用看到；
③ 应避免直接手改 `router.routes`（那是底层路由树），要用装饰器和 `include_router()`。
</details>
