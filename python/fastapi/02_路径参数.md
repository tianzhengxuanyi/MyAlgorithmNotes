## 一、章节笔记

### 1. 什么是路径参数

路径参数（Path Parameter）是 URL 路径中**动态变化**的那一段。FastAPI 使用与 Python 字符串格式化相同的 `{变量名}` 语法来声明：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/{item_id}")
async def read_item(item_id):
    return {"item_id": item_id}
```

路径参数 `item_id` 的值会作为参数 `item_id` 传递给路径操作函数。访问 `/items/foo` 得到 `{"item_id":"foo"}`。

### 2. 用类型注解声明类型

使用 Python 标准类型注解即可声明路径参数类型，一份声明同时获得**编辑器支持、数据解析、数据校验、自动文档**四重收益：

```python
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}
```

访问 `/items/3` 返回 `{"item_id":3}` —— 注意函数收到并返回的是 `int` 类型的 `3`，而不是字符串 `"3"`。FastAPI 通过类型声明自动完成"解析"。

### 3. 数据校验与错误结构

若传入的值无法转换为声明的类型（如 `/items/foo`、`/items/4.2`），FastAPI 返回 `422` 错误：

```json
{
  "detail": [
    {
      "type": "int_parsing",
      "loc": ["path", "item_id"],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "foo"
    }
  ]
}
```

- `loc`（location）精确指出错误发生在 `path` 的 `item_id` 上，便于调试与 API 联调。
- 所有校验都在幕后由 **Pydantic** 完成。
- `str`、`float`、`bool` 及众多复合类型都可用于类型注解。

### 4. 自动文档

基于同一份类型声明，FastAPI 生成符合 **OpenAPI** 标准的 schema，因此自带：

| 文档 | 地址 | 说明 |
|---|---|---|
| Swagger UI | `/docs` | 交互式文档，可直接在浏览器试调用 |
| ReDoc | `/redoc` | 备选文档 |
| OpenAPI JSON | `/openapi.json` | 原始模式，兼容大量第三方工具与代码生成器 |

文档中会正确显示路径参数类型为整数。

### 5. 顺序很重要

路径操作**按声明顺序依次匹配**，因此固定路径必须写在动态路径之前：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/users/me")                 # 必须先声明
async def read_user_me():
    return {"user_id": "the current user"}

@app.get("/users/{user_id}")          # 后声明
async def read_user(user_id: str):
    return {"user_id": user_id}
```

若顺序颠倒，`/users/me` 会被 `/users/{user_id}` 抢先匹配，`user_id` 得到值 `"me"`。

同理，**不要重复定义同一个路径操作**——路径首先匹配，始终使用第一个定义的：

```python
@app.get("/users")
async def read_users():
    return ["Rick", "Morty"]

@app.get("/users")            # 永远不会被执行
async def read_users2():
    return ["Bean", "Elfo"]
```

### 6. 预设值：用 Enum 限定可选值

若希望路径参数只能是若干预设值，使用标准 Python `Enum`。推荐继承 `StrEnum`（Python 3.11+），其成员本身是字符串，文档能正确渲染为 `string` 类型：

```python
from enum import StrEnum
from fastapi import FastAPI

class ModelName(StrEnum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"

app = FastAPI()

@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model_name": model_name, "message": "Deep Learning FTW!"}
    if model_name.value == "lenet":
        return {"model_name": model_name, "message": "LeCNN all the images"}
    return {"model_name": model_name, "message": "Have some residuals"}
```

关键用法：

| 操作 | 写法 | 说明 |
|---|---|---|
| 比较枚举成员 | `model_name is ModelName.alexnet` | 用 `is` 与枚举成员比较 |
| 获取枚举值 | `model_name.value` / `ModelName.lenet.value` | 得到底层字符串值 |
| 返回枚举成员 | `return {"model_name": model_name}` | 序列化为对应的值（如 `"alexnet"`） |

由于可用值已预定义，交互式文档会把它们展示为下拉选项。

### 7. 包含路径的路径参数（`:path` 转换器）

当路径参数本身要包含斜杠（如文件路径 `home/johndoe/myfile.txt`）时，用 Starlette 的 `path` 转换器：

```python
@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

- 语法：`{参数名:path}`，`:path` 表示匹配任意路径（含斜杠）。
- 访问 `/files//home/johndoe/myfile.txt`（`files` 与 `home` 之间用**双斜杠**）可让参数值以 `/` 开头。
- OpenAPI 标准本身不支持声明"内含路径"的参数，因此文档仍可用，但不会额外标注该参数应包含路径。

### 8. 易错点小结

- ✅ 路径参数**始终必填**——它就在 URL 里，没有默认值概念。
- ✅ 类型注解只写一次，同时驱动解析、校验与文档。
- ✅ 固定路径放前面，避免被动态路径"吃掉"。
- ✅ 想限定可选值用 `Enum`，不要用一堆 `if` 手动判断后返回 404。

## 二、NestJS 对比

| 维度 | FastAPI（Python） | NestJS（TypeScript） |
|---|---|---|
| 路由与参数声明 | 函数装饰器 `@app.get("/items/{item_id}")`，参数由 `{item_id}` 与同名函数参数对应 | 控制器类 + `@Controller('items')` / `@Get(':itemId')`，用 `@Param('itemId')` 注入 |
| 参数获取方式 | 按**名称**匹配函数签名，无需额外装饰器 | 必须用参数装饰器 `@Param()` / `@Param('name')` 显式取值 |
| 类型转换 | 由类型注解 `item_id: int` 自动完成（Pydantic） | 默认拿到 `string`，需 `ParseIntPipe` 等 Pipe 转换：`@Param('id', ParseIntPipe)` |
| 数据校验 | 类型注解即校验，错误由 Pydantic 生成统一 `422` 结构 | 依赖 `class-validator`，通常配合全局 `ValidationPipe` 对 DTO 校验 |
| 预设值 / 枚举 | 继承 `StrEnum` 并作为类型注解，文档自动生成下拉选项 | 用 TS `enum` + `@IsEnum(ModelName)` 装饰器校验 |
| 包含路径的参数 | 路径转换器 `{file_path:path}` | 通配路由 `@Get('files/*path')` 或 `@Get('files/:path(*)')`（依版本） |
| 路由顺序语义 | 按声明顺序**首个匹配生效**，固定路径须前置 | 按模块/控制器注册顺序匹配，同样需注意静态路由优先级 |
| 文档生成 | 类型声明自动进入 OpenAPI，`/docs` 零配置可见参数类型 | 需 `@nestjs/swagger` + `@ApiParam()` 补充参数说明才完整 |

**核心差异一句话**：FastAPI 把路径参数"写进路由字符串 + 同名类型注解"，参数名即契约，类型即校验与文档；NestJS 把路由与方法参数解耦，需用 `@Param` 显式取出、`ParseIntPipe`/`ValidationPipe` 显式转换与校验，换来的是更强的分层与可插拔管道能力。

## 三、针对性练习题

### 题 1（基础）

写一个 FastAPI 路径操作 `GET /items/{item_id}`，要求 `item_id` 为整数，并返回它。说明访问 `/items/42` 与 `/items/foo` 分别会发生什么。

<details>
<summary>参考答案</summary>

```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}
```

- `/items/42` → `{"item_id":42}`，返回的是 `int` 类型 `42`。
- `/items/foo` → `422` 校验错误，`type` 为 `int_parsing`，`loc` 为 `["path","item_id"]`，因为 `foo` 无法解析为整数。
</details>

### 题 2（理解）

为什么说"类型注解只写一次，却得到四重收益"？请列出这四重收益并说明它们都由什么驱动。

<details>
<summary>参考答案</summary>

四重收益：① 编辑器支持（错误检查、代码补全）；② 数据解析（字符串 → `int`）；③ 数据校验（非法值返回 422）；④ 自动生成 API 文档（`/docs`、`/redoc`）。

它们都由同一个 Python 类型注解驱动：底层由 Pydantic 做解析与校验，由 FastAPI 把类型信息写入 OpenAPI schema 再驱动文档。因此只需声明一次，无重复配置。
</details>

### 题 3（辨析/代码）

下面两段代码都能"工作"，但访问 `/users/me` 时行为不同，请指出区别并给出正确写法。

```python
# A
@app.get("/users/{user_id}")
async def read_user(user_id: str):
    return {"user_id": user_id}

@app.get("/users/me")
async def read_user_me():
    return {"user_id": "the current user"}
```

<details>
<summary>参考答案</summary>

A 中动态路径 `/users/{user_id}` 写在前面，会把 `/users/me` 抢先匹配，`user_id` 得到字符串 `"me"`，返回 `{"user_id":"me"}`，固定路由永远失效。

正确做法是把固定路径放前面：

```python
@app.get("/users/me")
async def read_user_me():
    return {"user_id": "the current user"}

@app.get("/users/{user_id}")
async def read_user(user_id: str):
    return {"user_id": user_id}
```

因为路径操作按声明顺序匹配，首个匹配生效。
</details>

### 题 4（进阶 · NestJS 迁移视角）

在 NestJS 中你这样读取路径参数：

```ts
@Get(':itemId')
getItem(@Param('itemId', ParseIntPipe) itemId: number) {
  return { itemId };
}
```

请写出功能等价的 FastAPI 代码，并说明 NestJS 的 `ParseIntPipe` 对应 FastAPI 的什么机制。

<details>
<summary>参考答案</summary>

```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/items/{item_id}")
async def get_item(item_id: int):
    return {"item_id": item_id}
```

NestJS 的 `ParseIntPipe` 负责把字符串路径参数转为数字并在失败时抛异常；FastAPI 中这一职责由 `item_id: int` 类型注解承担——Pydantic 自动完成转换，失败时返回结构统一的 `422` 响应。两者都是"转换 + 校验"，但 FastAPI 是声明式（类型即契约），NestJS 是管道式（需显式挂载 Pipe）。
</details>

### 题 5（思考）

想让 `GET /models/{model_name}` 只接受 `alexnet`、`resnet`、`lenet` 三个值，并且让文档里显示为下拉选项。请用 `StrEnum` 实现，并说明为什么推荐 `StrEnum` 而不是普通 `Enum`。

<details>
<summary>参考答案</summary>

```python
from enum import StrEnum
from fastapi import FastAPI

class ModelName(StrEnum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"

app = FastAPI()

@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    return {"model_name": model_name}
```

推荐 `StrEnum` 的原因：其成员既是枚举成员又是字符串，OpenAPI 能把类型正确渲染为 `string`，文档可展示可选值下拉框；而普通 `Enum` 的值是任意类型，文档渲染与序列化不如 `StrEnum` 直观。此外可用 `model_name is ModelName.alexnet` 比较、`model_name.value` 取值，返回给客户端时自动序列化为字符串。
</details>
