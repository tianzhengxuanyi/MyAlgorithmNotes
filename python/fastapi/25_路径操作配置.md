# 25 · 路径操作配置（Path Operation Configuration）

> 官方文档：<https://fastapi.tiangolo.com/zh/tutorial/path-operation-configuration/>
> 前置依赖：路径操作基础、响应模型（第 17 章） · 难度：⭐

## 一、章节笔记

### 1. 本章要解决什么问题

给路径操作附加**元数据** —— 状态码、文档标签、摘要、描述、响应描述、弃用标记等，让自动生成的 OpenAPI 文档更清晰。

> ⚠️ 本章所有参数都要**直接传给路径操作装饰器**（`@app.get(...)` 等），**不能**传给路径操作函数 —— 那是请求数据的位置。

### 2. 响应状态码

```python
from fastapi import FastAPI, status
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None
    tags: set[str] = set()

@app.post("/items/", status_code=status.HTTP_201_CREATED)
async def create_item(item: Item) -> Item:
    return item
```

- 直接传整数（如 `404`）或 `status` 快捷常量（如 `status.HTTP_201_CREATED`）。
- 状态码会用于响应，并写入 OpenAPI 概图。
- 技术细节：`fastapi.status` 与 `starlette.status` 相同（来自 Starlette）。

### 3. 标签（tags）

```python
@app.post("/items/", tags=["items"])
async def create_item(item: Item) -> Item:
    return item

@app.get("/items/", tags=["items"])
async def read_items():
    return [{"name": "Foo", "price": 42}]

@app.get("/users/", tags=["users"])
async def read_users():
    return [{"username": "johndoe"}]
```

- `tags` 接收 `str` 组成的 `list`（通常一个元素），OpenAPI 会自动添加，文档 UI 按标签分组。
- **大型应用推荐用 `Enum` 管理标签**，确保相关操作始终使用同一标签：

```python
from enum import Enum
from fastapi import FastAPI

app = FastAPI()

class Tags(Enum):
    items = "items"
    users = "users"

@app.get("/items/", tags=[Tags.items])
async def get_items():
    return ["Portal gun", "Plumbus"]

@app.get("/users/", tags=[Tags.users])
async def read_users():
    return ["Rick", "Morty"]
```

FastAPI 对 Enum 标签的支持与普通字符串相同。

### 4. 摘要与描述

```python
@app.post(
    "/items/",
    summary="Create an item",
    description="Create an item with all the information, name, description, price, tax and a set of unique tags",
)
async def create_item(item: Item) -> Item:
    return item
```

**从 docstring 获取长描述**：描述较长且多行时，写在函数的文档字符串中，FastAPI 会读取：

```python
@app.post("/items/", summary="Create an item")
async def create_item(item: Item) -> Item:
    """
    Create an item with all the information:

    - **name**: each item must have a name
    - **description**: a long description
    - **price**: required
    - **tax**: if the item doesn't have tax, you can omit this
    - **tags**: a set of unique tag strings for this item
    """
    return item
```

- docstring 支持 **Markdown**，能正确解析显示；注意保持缩进。

### 5. 响应描述

```python
@app.post(
    "/items/",
    summary="Create an item",
    response_description="The created item",
)
async def create_item(item: Item) -> Item:
    ...
```

- `response_description` **只描述响应**；`description` 一般描述**路径操作**本身。
- OpenAPI 规定每个路径操作都要有响应描述；未定义时 FastAPI 自动生成 `"Successful response"`。

### 6. 弃用路径操作

```python
@app.get("/elements/", tags=["items"], deprecated=True)
async def read_elements():
    return [{"item_id": "Foo"}]
```

传 `deprecated=True` 把路径操作标记为**弃用**（不删除），文档 UI 会显示弃用样式，与普通操作明显区分。

### 7. 参数速查表

| 参数 | 位置 | 作用 |
|---|---|---|
| `status_code` | 装饰器 | 响应状态码，写入 OpenAPI |
| `tags` | 装饰器 | 文档分组标签，支持 `list[str]` 或 Enum 列表 |
| `summary` | 装饰器 | 操作简短摘要 |
| `description` | 装饰器 | 操作详细描述（支持 Markdown） |
| （docstring） | 函数文档字符串 | 长描述的另一种来源，支持 Markdown |
| `response_description` | 装饰器 | 响应描述；默认 `"Successful response"` |
| `deprecated` | 装饰器 | 标记为弃用 |

### 8. 易错点

- ✅ 所有配置参数都放装饰器里，别放函数签名（那是 Query/Path/Body 参数的位置）。
- ✅ 标签用 Enum 可避免拼写不一致，适合大型应用。
- ✅ `description` 与 `response_description` 作用对象不同，别混淆。
- ✅ 弃用只加标记，端点仍可正常调用。

## 二、NestJS 对比

| 维度 | FastAPI（Python） | NestJS（TypeScript） |
|---|---|---|
| 配置位置 | 全部作为装饰器参数直接写在 `@app.get/post(...)` 上 | 文档元数据用 `@ApiOperation()`，状态码用 `@HttpCode()`，分属不同装饰器 |
| 状态码 | `status_code=status.HTTP_201_CREATED` | `@HttpCode(HttpStatus.CREATED)` |
| 标签 | `tags=["items"]`，支持 Enum 列表 | `@ApiOperation({ tags: ['items'] })` 或控制器级 `@ApiTags('items')` |
| 摘要/描述 | `summary=` / `description=`，或从函数 docstring 读取 | `@ApiOperation({ summary, description })`，docstring 默认不生效 |
| 响应描述 | `response_description="..."`，默认 `Successful response` | `@ApiResponse({ status: 200, description: '...' })` |
| 弃用标记 | `deprecated=True` | `@ApiOperation({ deprecated: true })` |
| 文档依赖 | 零配置，元数据自动进 OpenAPI | 需安装 `@nestjs/swagger` 并调用 `SwaggerModule.setup()` |
| 集中管理标签 | Python `Enum` 存放标签值 | TS `enum` / 常量 + `@ApiTags()` |

**核心差异一句话**：FastAPI 把状态码、标签、摘要、描述、响应描述、弃用标记等全部收敛到**同一个路径操作装饰器**的参数里，零配置即进入 OpenAPI；NestJS 把这些元数据拆到 `@HttpCode()`、`@ApiOperation()`、`@ApiTags()`、`@ApiResponse()` 等多个装饰器中，且依赖 `@nestjs/swagger` 显式挂载，配置更分散但粒度更细。

## 三、针对性练习题

### 题 1（基础）

写一个 `POST /items/`：状态码 201、标签 `["items"]`、摘要 `Create an item`、响应描述 `The created item`。

<details>
<summary>参考答案</summary>

```python
from fastapi import FastAPI, status
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str

@app.post(
    "/items/",
    status_code=status.HTTP_201_CREATED,
    tags=["items"],
    summary="Create an item",
    response_description="The created item",
)
async def create_item(item: Item) -> Item:
    return item
```

所有参数都写在装饰器里；若写进函数签名会被当作请求参数解析。
</details>

### 题 2（理解）

`description` 和 `response_description` 分别描述什么？不写 `response_description` 时默认值是什么？

<details>
<summary>参考答案</summary>

- `description` 描述**路径操作本身**（这个接口做什么），也可由函数 docstring 提供。
- `response_description` 只描述**响应**（成功时返回什么）。
- OpenAPI 要求每个操作都有响应描述，未提供时 FastAPI 自动填 `"Successful response"`。
</details>

### 题 3（辨析/代码）

下面想用函数参数代替装饰器参数，哪种可行？

```python
# A
@app.get("/items/", tags=["items"])
async def read_items(): ...

# B
@app.get("/items/")
async def read_items(tags=["items"]): ...
```

<details>
<summary>参考答案</summary>

只有 A 可行。`tags` 是路径操作**配置参数**，必须直接传给装饰器；写在函数签名里（B）会被解释为名为 `tags` 的**查询参数**，与文档分组无关。同理，`status_code`、`summary`、`deprecated` 等也都不能写进函数签名。
</details>

### 题 4（进阶 · NestJS 迁移视角）

NestJS 中你写：

```ts
@Post('items')
@ApiOperation({ summary: 'Create an item', tags: ['items'], deprecated: true })
@ApiResponse({ status: 201, description: 'The created item' })
@HttpCode(HttpStatus.CREATED)
create(@Body() dto: CreateItemDto) { return dto; }
```

写出等价的 FastAPI 代码，并指出配置组织方式的差异。

<details>
<summary>参考答案</summary>

```python
from fastapi import FastAPI, status
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
    name: str

@app.post(
    "/items/",
    status_code=status.HTTP_201_CREATED,
    tags=["items"],
    summary="Create an item",
    response_description="The created item",
    deprecated=True,
)
async def create_item(item: Item) -> Item:
    return item
```

差异：FastAPI 所有配置集中在**一个装饰器**的参数里，零配置即进 OpenAPI；NestJS 需拆成 `@ApiOperation()`、`@ApiResponse()`、`@HttpCode()` 三个装饰器，且必须先安装 `@nestjs/swagger` 并调用 `SwaggerModule.setup()` 才能生成文档。
</details>

### 题 5（思考）

大型应用里为什么要推荐用 `Enum` 存放 tags 而不是直接写字符串？请写出一个用 Enum 管理 `items`/`users` 标签并应用于两个端点的例子。

<details>
<summary>参考答案</summary>

大型应用标签很多，手写字符串容易出现拼写不一致（如 `'item'` 与 `'items'` 被当成两个分组），导致文档混乱。用 Enum 集中定义可保证引用一致、便于重构。

```python
from enum import Enum
from fastapi import FastAPI

app = FastAPI()

class Tags(Enum):
    items = "items"
    users = "users"

@app.get("/items/", tags=[Tags.items])
async def get_items():
    return ["Portal gun", "Plumbus"]

@app.get("/users/", tags=[Tags.users])
async def read_users():
    return ["Rick", "Morty"]
```

FastAPI 对 Enum 标签的支持与普通字符串完全相同。
</details>
