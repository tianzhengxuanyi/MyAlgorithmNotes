## 一、章节笔记

### 1. 本章要解决什么问题

用**最少的代码**跑起一个可返回 JSON、并自动生成交互式文档的 HTTP API。这是整个教程的地基。

### 2. 最小可运行应用

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}
```

保存为 `main.py`，运行：

```bash
uv run fastapi dev          # 开发模式（热重载），默认监听 127.0.0.1:8000
```

- `/docs` → Swagger UI 交互式文档
- `/redoc` → ReDoc 备选文档
- `/openapi.json` → OpenAPI 模式原始 JSON

### 3. 六个关键点

| 步骤 | 代码 | 说明 |
|---|---|---|
| ① 导入 | `from fastapi import FastAPI` | `FastAPI` 是直接继承 `Starlette` 的类 |
| ② 实例 | `app = FastAPI()` | 创建所有 API 的主交互对象 |
| ③ 路径操作装饰器 | `@app.get("/")` | 把下方函数绑定到「路径 `/` + GET 操作」 |
| ④ 路径操作函数 | `async def root():` | 请求到达时被调用；`async def` / `def` 均可 |
| ⑤ 返回内容 | `return {...}` | 可返回 dict/list/标量/Pydantic 模型/ORM 对象，自动转 JSON |
| ⑥ 部署 | `fastapi deploy` | 一条命令部署到 FastAPI Cloud（可选） |

**路径（Path）**：URL 中从第一个 `/` 起的部分，如 `/items/foo`。也叫端点（endpoint）或路由（route）。
**操作（Operation）**：即 HTTP 方法 —— `GET / POST / PUT / DELETE / PATCH / HEAD / OPTIONS / TRACE`。约定：`POST` 建、`GET` 读、`PUT` 更新、`DELETE` 删，但 FastAPI **不强制**语义。

### 4. 关于 OpenAPI 与「模式」

- **模式（Schema）**：对事物的抽象描述，不是实现代码。
- **OpenAPI**：规定「如何定义 API 模式」的规范；其中数据部分由 **JSON Schema** 标准生成。
- FastAPI 内置的两套文档、以及数十种第三方工具和客户端代码生成，全部由这份 OpenAPI 模式驱动 —— 这是 FastAPI「代码即文档」的根源。

### 5. 应用入口配置（entrypoint）

在 `pyproject.toml` 中声明，避免每次命令行传参，也便于 VS Code 扩展 / FastAPI Cloud 识别：

```toml
[tool.fastapi]
entrypoint = "main:app"
# 多文件结构时：
# entrypoint = "backend.main:app"
```

等价写法：`uv run fastapi dev main.py` 或 `uv run fastapi dev --entrypoint main:app`。

### 6. 易错点

- ✅ 返回的是 Python `dict`，不是 `json.dumps(...)` 字符串 —— FastAPI 自动序列化。
- ✅ `async def` 与 `def` 都能用；不确定时先用 `def`（涉及阻塞/并发再深入）。
- ✅ 开发用 `fastapi dev`，生产用 `fastapi run`。

## 二、NestJS 对比

| 维度 | FastAPI（Python） | NestJS（TypeScript） |
|---|---|---|
| 应用实例 | `app = FastAPI()` | `const app = await NestFactory.create(AppModule)` |
| 启动 | `fastapi dev` / `uvicorn` | `npm run start:dev`（底层 `nest start --watch`） |
| 路由声明 | 函数 + 装饰器 `@app.get("/")` | 控制器类 + 装饰器 `@Controller()` / `@Get()` |
| 处理器单位 | **函数**（路径操作函数） | **类中的方法**（handler） |
| 装饰器来源 | 框架内置、作用于函数 | 框架内置、作用于类/方法/参数，含 DI 元数据 |
| 组织方式 | 无强制结构，单文件即可起步 | 强制模块化：`Module → Controller → Provider` |
| 文档生成 | **内置**（OpenAPI + Swagger UI / ReDoc，零配置） | 需额外安装 `@nestjs/swagger` 并手动调用 `SwaggerModule.setup()` |
| 数据校验 | Pydantic 模型，基于类型注解 | DTO 类 + `class-validator` / `class-transformer` 装饰器 |
| 异步模型 | `async def` 事件循环 + 线程池 | Promise / async-await，基于 RxJS 与 Express/Fastify |
| 底层 | Starlette（ASGI） | Express（默认）或 Fastify（HTTP 适配器） |

**核心差异一句话**：FastAPI 以「函数 + 类型注解」为中心，靠标准（OpenAPI/JSON Schema）自动推导出文档与校验；NestJS 以「类 + 模块 + 依赖注入」为中心，强调分层与可测试性，文档与校验需显式接线。刚上手时 FastAPI 样板代码更少，大型团队协作时 NestJS 的强约定更有优势。

## 三、针对性练习题

### 题 1（基础）
写出一个 FastAPI 应用，定义 `GET /health`，返回 `{"status": "ok"}`。并说明访问哪个地址能看到自动生成的交互文档。

<details>
<summary>参考答案</summary>

```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/health")
async def health():
    return {"status": "ok"}
```

交互式文档地址：`http://127.0.0.1:8000/docs`（Swagger UI）；备选 `/redoc`；原始模式 `/openapi.json`。
</details>

### 题 2（理解）
`@app.get("/")` 中的 `"路径"` 与 HTTP 的 `"操作"` 分别指什么？为什么说「FastAPI 不强制 GET 一定用于读取」？

<details>
<summary>参考答案</summary>

- 路径：URL 中第一个 `/` 之后的部分（也叫端点/路由），用于区分资源和关注点。
- 操作：HTTP 方法（GET/POST/PUT/DELETE 等），在 OpenAPI 中称为 operation。
- FastAPI 只是把方法绑定到函数，不注入业务语义；`GET/POST` 的用途约定是开发规范而非框架约束。例如 GraphQL 场景常全部走 POST。
</details>

### 题 3（辨析）
下面两种写法都能工作吗？有什么区别？

```python
# A
@app.get("/")
async def root(): return {"msg": "hi"}
# B
@app.get("/")
def root(): return {"msg": "hi"}
```

<details>
<summary>参考答案</summary>

都能工作。FastAPI 会按定义方式处理：`async def` 直接在事件循环中运行（适合非阻塞 I/O）；普通 `def` 会被放进外部线程池执行（适合含阻塞操作的处理）。选择取决于是否有阻塞调用，初学阶段可先用 `def`。
</details>

### 题 4（进阶 · NestJS 迁移视角）
你在 NestJS 中习惯这样写：

```ts
@Controller()
export class AppController {
  @Get()
  root() { return { message: 'Hello World' }; }
}
```

请写出功能等价的 FastAPI 代码，并说明两者在「文档生成」上的差异。

<details>
<summary>参考答案</summary>

```python
from fastapi import FastAPI
app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}
```

差异：FastAPI 默认自动生成 OpenAPI 模式并挂载 `/docs` `/redoc`，无需任何额外配置；NestJS 需安装 `@nestjs/swagger`，用 `DocumentBuilder` + `SwaggerModule.createDocument()` / `setup()` 手动挂载，且请求/响应结构还需 `@ApiProperty()` 等装饰器补充才能完整。
</details>

### 题 5（思考）
为什么说「OpenAPI 模式」是 FastAPI 一切自动化能力的基石？请举出至少两个依赖它的能力。

<details>
<summary>参考答案</summary>

因为 FastAPI 从路径、参数、类型注解中生成一份机器可读的 OpenAPI 模式（数据部分遵循 JSON Schema），其他工具都消费这份模式。依赖它的能力包括：① `/docs` Swagger UI；② `/redoc`；③ 自动生成前端/移动端/物联网客户端代码；④ 各类基于 OpenAPI 的第三方工具集成。
</details>
