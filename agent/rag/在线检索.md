# RAG 在线检索

## 总览流程

```text
HTTP ChatController.chat 守卫、跳过超时SkipTimeout、返回结果封装Bypass
    -> ChatService.streamChat
    -> SseSenderProvider.create立刻建 SSE(请求头设置Content-type text/event-stream) 、推 meta（taskId）
    -> 落库用户消息、取排队许可ChatQueueLimiter.acquireChatFlow
    -> StreamChatPipeline 8 段：
       记忆 -> 改写 -> 意图 -> 歧义/闲聊短路
       -> 多通道检索 -> 空结果再短路
       -> 拼 Prompt -> 流式 LLM（首包探测 + 模型降级）
    -> SSE message / finish / done，assistant 落库
```

```mermaid
flowchart TD
  U[用户发 message] --> G[注入检测 + Token 日上限]
  G --> SSE[立刻 SSE + meta]
  SSE --> Q[排队限流]
  Q --> P[StreamChatPipeline]
  P --> M[loadMemory]
  M --> R[rewriteQuery]
  R --> I[resolveIntents]
  I --> A{歧义?}
  A -->|是| C1[澄清文案，结束]
  A -->|否| S{无意图或全 SYSTEM?}
  S -->|是| C2[闲聊 LLM]
  S -->|否| RET[多通道检索]
  RET --> E{KB+MCP 都空?}
  E -->|是| C2
  E -->|否| RAG[拼 RAG Prompt + 流式生成]
```
