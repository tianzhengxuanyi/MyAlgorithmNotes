# 「个人简历」版式规格（复刻自 resume_final.pdf）

后续按此格式生成简历时，**直接用 `build_resume.py` + 改 `content.json`**，不要重新设计版式。

## 一、来源与尺寸

- 原 PDF 画布 615.1×870pt，是 A4（595.3×841.9pt）等比放大 1.0333 的结果
- 本版式已换算回标准 A4，所有数值单位为 pt
- 页边距：上 9.0 / 下 22.0 / 左 18.4 / 右 21.9；正文净宽 555

## 二、配色

| 用途 | 色值 |
|---|---|
| 主色（标题、色块、竖线、粗条） | `#4E7282` |
| 辅色（金色细条、右上圆形图标） | `#C19F67` |
| 条目标题 / 基本信息关键词 | `#333333` |
| 正文 | `#555555` |

## 三、字体与字号

- 中文：微软雅黑；西文/数字：Arial（同一 run 内 ascii=Arial、eastAsia=微软雅黑）
- 姓名标题「个人简历」：27.5pt，主色，常规字重
- 板块标题：12pt，白色，常规字重
- 条目标题（单位/项目名/岗位）、教育院校与专业：10.5pt，`#333333`，**加粗**
- 正文：9.5pt，`#555555`
- 正文固定行距 16pt；条目头行距 18.9pt；基本信息每行 18.6pt

## 四、页面骨架（自上而下）

1. **标题区**：左上「个人简历」；右上两个金色圆形图标（毕业帽=教育、公文包=求职），直径 29pt，右对齐
2. **标题色条**：深色粗条高 13pt、宽 360（自页面左边缘起），留白 8pt，再接金色条（顶部内缩 4pt，即高 9pt）到页面右边缘
3. **左侧竖线**：贯穿整页，距页面左边缘 30pt，`#4E7282`，0.75pt（用页面边框实现）
4. **板块顺序**（固定）：基本信息 → 教育背景 → 工作经历 → 技能特长 → 项目经验

## 五、板块内部规格

**板块标题**：主色实心块 101.6×17.4pt，文字距块左边缘 17.9pt；块右侧一条 0.75pt 主色细线延伸到右边距，细线与色块底边齐平。
标题前留白 14pt，标题后留白 13.7pt。

**基本信息**：整体左缩进 25.9pt；6 行 × 两列键值对（标签列 55.6 / 值列 158.5 / 标签列 53 / 值列 188 / 照片列 66.6）。标签用全角空格对齐成 4 字宽（如「姓　　名」）后接「：」。照片 66.6×86.1pt 放在右侧，纵向居中，跨全部 6 行。

**教育背景 / 工作经历 / 项目经验 条目头**：左缩进 25.9pt，一行三栏——日期（左）｜单位或项目名（居中，中心位 277pt）｜岗位或成果定位（右对齐到 555pt），后两栏加粗。

**项目经验条目**：条目头下方依次是「技术栈：」「项目描述：」两行（标签加粗），再「核心工作与成果：」，随后 bullet 列表。

**技能特长**：每行「标签：内容」，标签加粗，左缩进 25.9pt。

**项目符号**：`•` 距左 31.3pt，正文续行 40.1pt（悬挂缩进 8.8pt），行距 16pt。

## 六、内容文件结构（content.json）

```json
{
  "title": "个人简历",
  "photo": "assets/photo.png",
  "icons": ["assets/icon-edu.png", "assets/icon-job.png"],
  "basic": {"section": "基本信息", "rows": [[["标签", "值"], ["标签", "值"]]]},
  "sections": [
    {"type": "entries", "title": "教育背景", "items": [{"date": "", "org": "", "detail": ""}]},
    {"type": "entries", "title": "工作经历", "items": [{"date": "", "org": "", "detail": "", "bullets": [""]}]},
    {"type": "skills", "title": "技能特长", "items": [["标签", "内容"]]},
    {"type": "projects", "title": "项目经验", "items": [{
        "date": "", "org": "", "detail": "",
        "meta": [["技术栈", ""], ["项目描述", ""]],
        "bulletsTitle": "核心工作与成果", "bullets": [""]
    }]}
  ]
}
```

- 换岗位投递：只改 `content.json`，版式不动
- 换照片：替换 `assets/photo.png`，或命令行 `--photo=新照片.png`
- 没有照片：删掉 `photo` 字段，基本信息自动占满整宽
- 增删板块：在 `sections` 里增删对应对象即可，标题色块与间距自动跟随
- 强制分页：给某个 section 加 `"pageBreak": true`，该板块从新页开始（用于「项目经验」整块另起一页，避免标题孤行）
- 换整套内容：复制 `content.json` 为 `content_岗位名.json`，用 `python build_resume.py content_岗位名.json 输出.docx` 生成，互不影响

## 七、生成与校验

```bash
# 生成
python build_resume.py content.json 输出.docx

# 校验（需本机 Word）：Word 打开 → 另存 PDF → 与原版逐项比对坐标
```

⚠️ 本机存在文档加密客户端：Word 直接导出 `.pdf`/`.docx` 会被加密导致第三方工具读不了。导出时先存成 `.bin`（格式仍选 PDF），再用 Python 复制为 `.pdf` 即可读取；用户自己正常保存 docx/PDF 不受影响。

## 八、与原版的已知微小差异

- 右上两个圆形图标比原版高约 8pt（受行内图片基线对齐限制，视觉上无感）
- 第二页左侧竖线延伸至页底（原版止于正文末尾）
- 原版板块标题色块左下角有一段深色小装饰块，本版式未复刻
