- keyof 是一个单目运算符，接受一个对象类型作为参数，返回该对象的所有键名组成的联合类型。
```ts
// string | number | symbol
type KeyT = keyof any;

type KeyT = keyof object;  // never

// 示例二
interface T {
  [prop: string]: number;
}
// string|number JavaScript 属性名为字符串时，包含了属性名为数值的情况，因为数值属性名会自动转为字符串。
type KeyT = keyof T;
```
- keyof 会返回数组的所有键名，包括数字键名和继承的键名。
- 对于联合类型，keyof 返回成员共有的键名。
- 对于交叉类型，keyof 返回所有键名。
- keyof 的作用
  1. 精确表达返回值类型。
    ```ts
    function prop<Obj, K extends keyof Obj>(
      obj:Obj, key:K
    ):Obj[K] {
      return obj[key];
    }
    ```
  1. 用于属性映射`-readonly` `+readonly` `-?` `+?`
    ```ts
    type Mutable<Obj> = {
      -readonly [Prop in keyof Obj]-?: Obj[Prop];
    };
    // 用法
    type MyObj = {
      readonly foo?: number;
    }
    // 等于 { foo: number; }
    type NewObj = Mutable<MyObj>;
    ```

- `in`运算符用来取出（遍历）联合类型的每一个成员类型。`[Prop in keyof Obj]`表示取出对象Obj的每一个键名。
- 方括号运算符（[]）用于取出对象的键值类型，比如T[K]会返回对象T的属性K的类型。
  - 参数如果是联合类型，那么返回的也是联合类型。
  - 方括号里面不能有值的运算。
- 条件运算符`extends...?:`可以根据当前类型是否符合某种条件，返回不同的类型。
  - `T extends U ? X : Y` extends用来判断，类型T是否可以赋值给类型U，即T是否为U的子类型
  - 判断的类型是一个联合类型，那么条件运算符会展开这个联合类型。
    ```ts
    (A|B) extends U ? X : Y
    // 等同于
    (A extends U ? X : Y) |
    (B extends U ? X : Y)
    ```
  - 如果不希望联合类型被条件运算符展开，可以把extends两侧的操作数都放在方括号里面。
    ```ts
    // 示例一
    type ToArray<Type> =
      Type extends any ? Type[] : never;
    // string[]|number[]
    type T = ToArray<string|number>;
    // 示例二
    type ToArray<Type> =
      [Type] extends [any] ? Type[] : never;
    // (string | number)[]
    type T = ToArray<string|number>;
    ```
- infer关键字用来定义泛型里面推断出来的类型参数，而不是外部传入的类型参数。通常跟条件运算符一起使用，用在extends关键字后面的父类型之中。
- 函数返回布尔值的时候，可以使用is运算符，限定返回值与参数之间的关系。
- TypeScript 允许使用模板字符串，构建类型。
  - 可以引用的类型一共6种，分别是 string、number、bigint、boolean、null、undefined。
  - 如果引用一个联合类型，那么它返回的也是一个联合类型，即模板字符串可以展开联合类型。
    ```ts
    type T = 'A'|'B';
    // "A_id"|"B_id"
    type U = `${T}_id`;

    type T = 'A'|'B';
    type U = '1'|'2';
    // 'A1'|'A2'|'B1'|'B2'
    type V = `${T}${U}`;
    ```

- 映射（mapping）指的是，将一种类型按照映射规则，转换成另一种类型，通常用于对象类型。
  - 映射类型语法：`{ [P in keyof Obj]: Obj[P] }`
  - +修饰符：写成+?或+readonly，为映射属性添加?修饰符或readonly修饰符。
  - -修饰符：写成-?或-readonly，为映射属性移除?修饰符或readonly修饰符。
  - as键名重映射 `{ [P in keyof T as ``get${Capitalize<string & P>}``]: () => T[P]; }`
  - 键名重映射还可以过滤掉某些属性。
  ```ts
    // 将不是string类型的属性名重映射为never
    {
      [K in keyof T
        as T[K] extends string ? K : never]: string
    }
  ```
  - 任意的联合类型都可以用来进行键名重映射

## [类型工具实现](https://www.bookstack.cn/read/wangdoc-typescript-tutorial/docs-utility.md#%3Ccode%3EOmitThisParameter%3CType%3E%3C/code%3E)

- **`Awaited<Type>`**
  - 用途：解 Promise 嵌套，获取 Promise 解析后的类型；递归剥除 `Promise<T>`，`Awaited<Promise<Promise<string>>>` → `string`
  - 注意：只处理 Promise 类型，不会做运行时解包；不捕获 reject 类型；对非 Promise原样返回。

- **`ConstructorParameters<Type>`**
  - 用途：提取**构造函数**的参数元组类型；`ConstructorParameters<typeof Date>` → `[value?: string | number | Date]`
  - 注意：传入必须是类的构造器类型（`typeof Class`），不是实例；普通函数传入返回 `never`。

- **`Exclude<UnionType, ExcludedMembers>`**
  - 用途：从联合类型中剔除指定成员。`Exclude<'a'|'b'|'c','a'>` → `'b'|'c'`
  - 注意：**作用于联合类型**，不是对象；分发条件类型；不能用于对象属性剔除（对象用 `Omit`）。

- **`Extract<Type, Union>`**
  - 用途：从联合类型中**保留匹配**的成员，其余剔除。`Extract<'a'|'b'|'c','a'|'b'>` → `'a'|'b'`
  - 注意：和 `Exclude` 相反；同样是联合分发；常用于过滤联合中子类型。

- **`InstanceType<Type>`**
  - 用途：获取构造函数对应的实例类型。`InstanceType<typeof Date>` → `Date`
  - 注意：入参必须是类构造器 `typeof Cls`；不能传实例对象本身。

- **`NonNullable<Type>`**
  - 用途：移除类型中的 `null | undefined`。`NonNullable<string | null | undefined>` → `string`
  - 注意：不会过滤 `void`、`never`；不会运行时判空，仅类型层面。

- **`Omit<Type, Keys>`**
  - 用途：对象类型，剔除指定键，返回新对象。`Omit<{a:number,b:string},'a'>` → `{b:string}`
  - 注意：第二个参数可以是联合；TS4.5+稳定；不能用于联合对象；`Keys` 只能是字符串字面量联合。
  - `type MyOmit<T, K extends keyof T> = Pick<T, Exclude<keyof T, K>>;`

- **`OmitThisParameter<Type>`**
  - 用途：移除函数的 `this` 伪参数，得到干净函数类型。
  - 注意：只处理带 `(this:T)` 的函数；非函数原样返回；**不能用于对象字面this绑定（那是 ThisType）**。

- **`Parameters<Type>`**
  - 用途：提取普通函数的参数元组类型。`Parameters<(a:number)=>void>` → `[a:number]`
  - 注意：传入普通函数类型；**不能传类实例，要拿构造器参数用 ConstructorParameters**。
  - `type MyParameters<T extends (...args: any[]) => any> = T extends (...args: infer P) => any ? P : never; `

- **`Partial<Type>`**
  - 用途：把对象所有属性变为可选。`Partial<{a:number}>` → `{a?:number}`
  - 注意：**浅层**，不会递归嵌套对象；数组不会变化；不处理联合。

- **`Pick<Type, Keys>`**
  - 用途：从对象中挑选指定键生成新类型。`Pick<{a:number,b:string},'a'>` → `{a:number}`
  - 注意：第二个参数支持字面量联合；键必须存在于源类型。

- **`Readonly<Type>`**
  - 用途：对象全部属性变为只读。`Readonly<{a:number}>` → `{readonly a:number}`
  - 注意：浅层只读；仅类型层面，运行时不阻止修改；数组用 `ReadonlyArray`。

- **`Record<Keys, Type>`**
  - 用途：构造一个键为 `Keys`、值为 `Type` 的对象类型。`Record<'a'|'b',number>` → `{a:number;b:number}`
  - 注意：Keys 必须是 string/number/symbol；常用于字典；不会校验对象真实存在哪些key。

- **`Required<Type>`**
  - 用途：把对象所有可选属性变为必选。`Required<{a?:number}>` → `{a:number}`
  - 注意：浅层；会把 `?` 移除，同时去掉属性上的 `undefined`。

- **`ReadonlyArray<Type>`**
  - 用途：只读数组类型，禁止调用 push/splice 等可变方法。
  - 注意：不能 new；普通数组可以赋值给 ReadonlyArray，反过来不行。

- **`ReturnType<Type>`**
  - 用途：提取函数返回值类型。`ReturnType<()=>string>` → `string`
  - 注意：传入函数类型；构造函数要用 `InstanceType`；不执行函数，仅类型推导。
  - `type MyReturnType<T extends (...args: any) => any> = T extends (...args: any) => infer R ? R : never;`

- **`ThisParameterType<Type>`**
  - 用途：提取函数伪参数 `this:T` 的类型；无this返回 `unknown`。
  - 注意：仅针对函数；**不作用对象字面量**；和 `OmitThisParameter` 配对使用。

- **`ThisType<Type>`**
  - 用途：标记对象字面量内方法的 `this` 上下文；空接口，编译器魔法标记。
  - 注意：需要开启 `noImplicitThis: true`；**只对对象字面量生效，不能修饰函数类型**；不会增加对象实际字段。

> 注意：仅类型层面转换，**运行时无效果，只用于类型推导**

- **`Uppercase<StringType>`**
  - 用途：字符串类型全部转大写。`Uppercase<'abc'>` → `'ABC'`
  - 注意：仅对字符串字面量生效；传入普通 `string` 返回 `string`。

- **`Lowercase<StringType>`**
  - 用途：字符串类型全部转小写。`Lowercase<'ABC'>` → `'abc'`
  - 注意：仅对字符串字面量生效；传入普通 `string` 返回 `string`。

- **`Capitalize<StringType>`**
  - 用途：首字母大写，其余不变。`Capitalize<'abc'>` → `'Abc'`
  - 注意：仅对字符串字面量生效；传入普通 `string` 返回 `string`。
  ```ts
  type lowerToUpper = {
    a: 'A', b: 'B', c: 'C', d: 'D', e: 'E', f: 'F', g: 'G',
    h: 'H', i: 'I', j: 'J', k: 'K', l: 'L', m: 'M', n: 'N',
    o: 'O', p: 'P', q: 'Q', r: 'R', s: 'S', t: 'T', u: 'U',
    v: 'V', w: 'W', x: 'X', y: 'Y', z: 'Z'
  }
  type MyCapitalize<S extends string> = S extends `${infer F}${infer R}` ? `${F extends keyof lowerToUpper ? lowerToUpper[F] : F}${R}` : S;
  ```

- **`Uncapitalize<StringType>`**
  - 用途：首字母小写，其余不变。`Uncapitalize<'Abc'>` → `'abc'`
  - 注意：仅对字符串字面量生效；传入普通 `string` 返回 `string`。

}```

- type、module、moduleResolution的区别
| 属性 | 作用 | 常用值 | 值含义 |
| ---- | ---- | ---- | ---- |
| target | TS语法降级目标 | ES5 | 降级到ES5，兼容老浏览器 |
| | | ES2020 | 保留?. ?? 等语法 |
| | | ESNext | 不降级，保留最新JS语法 |
| module | 输出模块规范 | CommonJS | 输出require/module.exports（老Node） |
| | | ESNext | 原生ESM，Vite/Rollup打包用 |
| | | NodeNext | Node自动识别cjs/mjs，Nest ESM推荐 |
| moduleResolution | import模块查找策略 | Classic | 旧方案，废弃 |
| | | Node | TS4.7前老Node查找规则 |
| | | NodeNext | Node ESM查找规则，Node项目首选 |
| | | Bundler | Webpack/Vite打包器专用，前端首选 |

**推荐组合**
前端打包(Vite/Webpack):
"target":"ESNext", "module":"ESNext", "moduleResolution":"Bundler"

Nest Node ESM:
"target":"ES2022", "module":"NodeNext", "moduleResolution":"NodeNext"

Node CommonJS老项目:
"target":"ES2020", "module":"CommonJS", "moduleResolution":"Node"
