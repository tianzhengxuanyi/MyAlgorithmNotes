# NestJS 循环依赖（精简笔记）
> 文档来源：[https://docs.nestjs.cn/fundamentals/circular](https://docs.nestjs.cn/fundamentals/circular)‑dependency

## 概念
循环依赖：A依赖B，B同时又依赖A；分为**提供者(service)循环依赖**、**模块(module)循环依赖**。
> 优先重构代码消除循环；实在避免不了才用`forwardRef()`。
> ⚠️ 桶文件`index.ts`集中导出容易引发循环依赖，尽量避开。

## 1、Service（提供者）互相依赖
**两边都要加 `@Inject(forwardRef(() => 类名))`**
```typescript
// CatsService
@Injectable()
export class CatsService {
  constructor(
    @Inject(forwardRef(() => CommonService))
    private commonService: CommonService
  ) {}
}

// CommonService
@Injectable()
export class CommonService {
  constructor(
    @Inject(forwardRef(() => CatsService))
    private catsService: CatsService
  ) {}
}
```
> 注意：构造函数实例化顺序不确定；`REQUEST`作用域提供者搭配循环依赖可能出现`undefined`。

备选方案：`ModuleRef`，运行时手动从容器拿实例，不在构造函数注入。

## 2、模块之间互相导入
**两边imports都套上`forwardRef(() => 模块类)`**
```typescript
// CommonModule
@Module({
  imports: [forwardRef(() => CatsModule)]
})
export class CommonModule {}

// CatsModule
@Module({
  imports: [forwardRef(() => CommonModule)]
})
export class CatsModule {}
```

## ✅ 关键要点
1. **双向都必须写 forwardRef，只写一边无效**；
2. `forwardRef`是延迟引用，不是根治，优先重构代码；
3. 慎用桶文件index.ts导出，会产生隐形循环；
4. `Scope.REQUEST` + 循环依赖有坑，可能拿到undefined。
