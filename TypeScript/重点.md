- tsc：编译器 ts-node：运行ts文件
- 编译选项noImplicitAny
- unknown类型：任何类型都可以赋值给unknown类型，但是unknown类型不能赋值给其他类型(除了any、unknown类型)
- never：可以赋值给任何类型
- 集合论
- 大写类型同时包含包装对象和字面量两种情况，小写类型只包含字面量，不包含包装对象。String和string
- 编译选项strictNullChecks undefined和null就不能赋值给其他类型的变量（除了any类型和unknown类型）。
- Object:除了undefined和null这两个值不能转为对象，其他任何值都可以赋值给Object类型。
- {}是Object简写
- object类型只包含对象、数组和函数
- Object类型和object类都只包含 内置对象原生的属性和方法
- 元组成员的类型可以添加问号后缀（?），表示该成员是可选的。
- unique symbol，它表示单个的、某个具体的 Symbol 值。只能用const命令声明
- “函数重载”的类型声明方法是，逐一定义每一种情况的类型，从上往下检查匹配
- 构造函数的类型
```ts
// 参数列表前加new
type AnimalConstructor = new () => Animal;
// 对象形式
type F = {
  new (s:string): object;
  (n?:number): number; // 添加这个表示F可以作为普通函数调用
}

interface ErrorConstructor {
  new (message?: string): Error;
}
```
- 严格对象字面量检查
```ts
type MyObj = {
  x: number;
  y: number;
};

// case1 对象字面量直接赋值
const o1: MyObj = { x: 1 }; // 缺少y →报错
const o2: MyObj = { x: 1, y: 1, z: 1 }; //字面量多了z →报错
```
- 结构类型原则。判断一个对象是否兼容目标类型：只要目标类型所有必需属性都存在即可，允许对象拥有额外多余属性。
```ts
// case2 先存到变量，再赋值
const B = { x: 1, y: 1, z:1 }; //B的类型是 {x:number,y:number,z:number}
const A: MyObj = B; // ✅编译通过
```
- 最小可选属性规则。 某个类型的所有属性都是可选的，那么该类型的对象必须至少存在一个可选属性，不能所有可选属性都不存在。
- 空对象添加属性。如果确实需要分步声明，一个比较好的方法是，使用扩展运算符（...）合成一个新对象。
- 强制使用没有任何属性的对象。
  ```ts
  interface WithoutProperties {
    [key: string]: never;
  }

  // 报错
  const a:WithoutProperties = { prop: 1 };
  ```
  - interface继承时：子接口与父接口存在同名属性，那么子接口的属性会覆盖父接口的属性。注意，子接口与父接口的同名属性必须是类型兼容的，不能有冲突，否则会报错。
  - interface继承时：如果多个父接口存在同名属性，那么这些同名属性不能有类型冲突，否则会报错。
  - interface 可以继承对象类型的type、class。
  - 同名接口合并时，同一个属性如果有多个类型声明，彼此不能有类型冲突
